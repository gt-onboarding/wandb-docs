---
title: 조직 활동 보기
---

이 페이지에서는 W&amp;B 조직의 활동 내역을 확인하는 방법을 설명합니다. 계속하려면 배포 유형을 선택하세요.

<div id="view-user-status-and-activity">
  ## 사용자 상태 및 활동 보기
</div>

<Tabs>
  <Tab title="Dedicated Cloud / Self-Managed">
    1. **Organization Dashboard**로 이동합니다.

       * **Dedicated Cloud**: `https://<org-name>.io/org/dashboard/`. `<org-name>`을(를) 조직 이름으로 변경합니다.
       * **Self-Managed**: `https://<YOUR-W&B-SERVER-IP>/org/dashboard`. `<YOUR-W&B-SERVER-IP>`을(를) 배포 환경의 IP 주소로 변경합니다.

       **Users** 탭이 기본으로 열리며, 조직의 모든 사용자가 표시됩니다.
    2. 사용자 상태별로 목록을 정렬하려면 **Last Active** 열 헤더를 클릭합니다. 각 사용자의 상태는 다음 중 하나입니다.
       * **Invite pending**: 초대가 전송되었지만 아직 수락되지 않았습니다.
       * **A timestamp**: 사용자가 초대를 수락하고 최소 한 번 이상 로그인했습니다. 타임스탬프는 가장 최근 활동 시점을 나타냅니다.
       * **Deactivated**: 관리자가 사용자의 접근 권한을 해지했습니다.
       * **No status**: 하이픈으로 표시됩니다. 사용자가 과거에는 활동했지만 지난 6개월 동안은 활동하지 않았습니다.
    3. 사용자의 **Last Active** 필드 위에 마우스를 올리면 사용자가 추가된 날짜와 총 활성 일수를 확인할 수 있습니다.

    사용자가 *active* 상태로 간주되는 경우는 다음과 같습니다.

    * W&amp;B에 로그인한 경우
    * W&amp;B App의 어떤 페이지든 연 경우
    * 실행을 기록한 경우
    * SDK를 사용하여 실험을 추적한 경우
    * 어떤 방식으로든 W&amp;B 서버와 상호작용한 경우
  </Tab>

  <Tab title="Multi-tenant Cloud">
    1. [**Members** 페이지](https://wandb.ai/account-settings/wandb/members/)를 엽니다. 표에는 조직의 모든 사용자가 표시됩니다.
    2. **Last Active** 열 헤더를 클릭하여 사용자 상태별로 정렬합니다. 각 사용자의 상태는 다음 중 하나입니다.
       * **A timestamp**: 사용자가 최소 한 번 이상 로그인했습니다. 타임스탬프는 가장 최근 활동 시점을 나타냅니다.
       * **No status**: 하이픈으로 표시됩니다. 사용자가 아직 조직 내에서 활동한 적이 없습니다.

    사용자는 2025년 5월 8일 이후에 조직 범위에서 감사 로그에 기록되는 작업을 수행하면 *active* 상태로 간주됩니다. 전체 목록은 **Audit logging**의 [Actions](/ko/platform/hosting/monitoring-usage/audit-logging#actions)를 참조하십시오.
  </Tab>
</Tabs>

<div id="view-activity-over-time">
  ## 시간 경과에 따른 활동 내역 보기
</div>

<Tabs>
  <Tab title="Dedicated Cloud / Self-Managed">
    지정한 기간 동안 얼마나 많은 사용자가 활동했는지 확인하려면 **Activity** 탭을 사용합니다.

    1. **Organization Dashboard**를 엽니다. [사용자 활동 보기](#view-user-activity)를 참조하세요.
    2. **Activity**를 클릭합니다.
    3. 다음 차트를 확인합니다.
       * **Total active users**: 선택한 기간(기본값 3개월) 동안의 고유 활성 사용자 수입니다.
       * **Users active over time**: 해당 기간(기본값 6개월) 동안 활성 사용자 수의 변동입니다. 포인트 위에 마우스를 올리면 해당 날짜의 정확한 수를 확인할 수 있습니다.

    보고 기간을 변경하려면 차트 상단의 드롭다운 메뉴를 사용합니다. 선택 가능한 옵션은 Last 30 days, Last 3 months, Last 6 months, Last 12 months, All time 입니다.
  </Tab>

  <Tab title="Multi-tenant Cloud">
    집계된 활동 내역을 보려면 **Activity Dashboard**를 사용합니다.

    1. W&amp;B App 우측 상단에서 사용자 아이콘을 클릭합니다.
    2. **Account** 아래에서 **Users**를 클릭합니다.
    3. 사용자 테이블 상단의 Activity Panel을 확인합니다.
       * **Active user count**: 선택한 기간(기본값 3개월) 동안의 고유 활성 사용자 수입니다.
       * **Weekly active users**: 주당 활성 사용자 수입니다.
       * **Most active user**: 활동 일수와 마지막 활동 날짜를 기준으로 상위 10명의 사용자를 표시합니다.
    4. 날짜 범위를 변경하려면 우측 상단의 날짜 선택기를 클릭하고 다음 중 새 값을 선택합니다: 7 days, 30 days(기본값), 90 days, 6 months, 12 months. 모든 차트는 자동으로 업데이트됩니다.
  </Tab>
</Tabs>

<div id="export-user-details">
  ## 사용자 상세 정보 내보내기
</div>

**Users** 탭에서 각 사용자의 상세 정보(사용자 이름, 이메일 주소, 마지막 활동 시각, 역할 등)가 포함된 CSV 파일을 다운로드할 수 있습니다.

<Tabs>
  <Tab title="전용 클라우드 / 셀프 매니지드">
    1. **Users** 탭에서 **Invite new user** 오른쪽의 **…** 작업 메뉴를 클릭합니다.
    2. **Export as CSV**를 클릭합니다.

    ### CSV 스키마 내보내기

    CSV 내보내기에서는 쉼표(`,`)를 구분 기호로 사용하고, 문자열은 큰따옴표로 감싸며, 다음 열을 정의하는 헤더 행을 포함합니다:

    * `"이름"`
    * `"사용자 이름"`
    * `"조직 역할"`
    * `"Models 시트"`
    * `"Weave 액세스"`
    * `"이메일"`
    * `"팀"`
    * `"마지막 활동 시각"`
  </Tab>

  <Tab title="멀티 테넌트 클라우드">
    1. **Users** 탭에서 오른쪽 상단의 **…** 작업 메뉴를 클릭합니다.
    2. 파일을 다운로드하려면 **Export as CSV**를 선택합니다.

    ### CSV 스키마 내보내기

    CSV 내보내기에서는 쉼표(`,`)를 구분 기호로 사용하고, 문자열은 큰따옴표로 감싸며, 다음 열을 정의하는 헤더 행을 포함합니다:

    * `"이름"`
    * `"사용자 이름"`
    * `"마지막 활동 시각"`
    * `"역할"`
    * `"이메일"`
    * `"팀"`
    * `"상태"`
    * `"리포트 수"`
    * `"실행 수"`
    * `"활성 일수"`
    * `"Models 시트"`
    * `"Weave 액세스"`
  </Tab>
</Tabs>
