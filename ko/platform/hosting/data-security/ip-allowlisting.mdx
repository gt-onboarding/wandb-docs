---
title: 전용 클라우드 IP 허용 목록 구성
---

[Dedicated Cloud](/ko/platform/hosting/hosting-options/dedicated_cloud) 인스턴스에 대한 액세스를 승인된 IP 주소 목록으로만 제한할 수 있습니다. 이는 AI 워크로드에서 W&amp;B API로의 액세스와 사용자 브라우저에서 W&amp;B 앱 UI로의 액세스 모두에 적용됩니다. Dedicated Cloud 인스턴스에 IP 허용 목록이 설정되면, W&amp;B는 허용되지 않은 다른 위치에서 오는 모든 요청을 거부합니다. Dedicated Cloud 인스턴스에 대한 IP 허용 목록 구성을 위해서는 W&amp;B 팀에 문의하세요.

IP 허용 목록 기능은 AWS, Google Cloud, Azure의 Dedicated Cloud 인스턴스에서 사용할 수 있습니다.

IP 허용 목록은 [secure private connectivity](./private-connectivity)와 함께 사용할 수 있습니다. IP 허용 목록을 secure private connectivity와 함께 사용하는 경우, 가능하다면 AI 워크로드에서 발생하는 모든 트래픽과 사용자 브라우저에서 발생하는 트래픽의 대부분에는 secure private connectivity를 사용하고, 권한 있는 위치에서의 인스턴스 관리를 위해서는 IP 허용 목록을 사용하는 구성을 W&amp;B에서 권장합니다.

<Warning>
  W&amp;B는 개별 `/32` IP 주소 대신 회사 또는 비즈니스 이그레스 게이트웨이에 할당된 [CIDR 블록](https://en.wikipedia.org/wiki/Classless_Inter-Domain_Routing)을 사용할 것을 강력히 권장합니다. 개별 IP 주소를 사용하는 방식은 확장성이 없으며, 클라우드별로 엄격한 제한이 있습니다.
</Warning>
