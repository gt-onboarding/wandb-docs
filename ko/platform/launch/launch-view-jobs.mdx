<div id="view-jobs">
  ## 작업 보기
</div>

W&B App에서 큐에 추가된 작업을 확인합니다.

1. https://wandb.ai/home 에서 W&B App으로 이동합니다.
2. 왼쪽 사이드바의 **Applications** 섹션에서 **Launch**를 선택합니다.
3. **All entities** 드롭다운을 클릭한 다음, 해당 Launch 작업이 속한 엔터티를 선택합니다.
4. Launch Application 페이지에서 접이식 UI를 펼쳐 해당 큐에 추가된 작업 목록을 확인합니다.

<Note>
launch agent가 launch 작업을 실행하면 실행이 생성됩니다. 즉, 목록에 표시된 각 실행은 해당 큐에 추가된 특정 작업에 대응합니다.
</Note>

예를 들어, 아래 이미지는 `job-source-launch_demo-canonical`이라는 작업에서 생성된 두 개의 실행을 보여줍니다. 이 작업은 `Start queue`라는 큐에 추가되었습니다. 큐에 첫 번째로 표시된 실행의 이름은 `resilient-snowball`이고, 두 번째로 표시된 실행의 이름은 `earthy-energy-165`입니다.

W&B App UI에서 launch 작업으로부터 생성된 실행에 대한 추가 정보를 확인할 수 있습니다. 예를 들면 다음과 같습니다:

- **Run**: 해당 작업에 할당된 W&B 실행의 이름
   - **Job ID**: 작업의 이름 
   - **Project**: 실행이 속한 프로젝트의 이름
   - **Status**: 큐에 있는 실행의 상태 
   - **Author**: 실행을 생성한 W&B 엔터티
   - **Creation date**: 큐가 생성된 시점의 타임스탬프
   - **Start time**: 작업이 시작된 시점의 타임스탬프
   - **Duration**: 작업 실행을 완료하는 데 걸린 시간(초)

<div id="list-jobs">
  ## 작업 목록 확인
</div>

W&amp;B CLI를 사용하여 특정 프로젝트 내에 있는 작업 목록을 확인할 수 있습니다. `wandb job list` 명령을 사용하고, 해당 launch 작업이 속한 프로젝트 이름과 엔터티를 각각 `--project` 및 `--entity` 플래그로 전달하십시오.

```bash
 wandb job list --entity your-entity --project project-name
```


<div id="check-the-status-of-a-job">
  ## 작업 상태 확인
</div>

다음 표는 대기 중인 실행이 가질 수 있는 상태를 정의합니다:

| 상태 | 설명 |
| --- | --- |
| **Idle** | 실행이 큐에 있지만 활성 에이전트가 없습니다. |
| **Queued** | 실행이 큐에서 에이전트가 처리하기를 기다리고 있습니다. |
| **Pending** | 실행이 에이전트에 할당되었지만 아직 시작되지 않았습니다. 이는 클러스터에서 사용할 수 있는 리소스가 없기 때문일 수 있습니다. |
| **Running** | 실행이 현재 실행 중입니다. |
| **Killed** | 작업이 사용자에 의해 강제로 중지되었습니다. |
| **Crashed** | 실행이 데이터 전송을 중단했거나 정상적으로 시작되지 않았습니다. |
| **Failed** | 실행이 0이 아닌 종료 코드로 종료되었거나 실행이 시작되지 못했습니다. |
| **Finished** | 작업이 성공적으로 완료되었습니다. |
