---
title: '`wandb launch -d` 또는 `wandb job create image`가 Docker 아티팩트 전체를 업로드하고 레지스트리에서 이미지를 pull 하지 않는 건가요?'
---

아니요, `wandb launch -d` 명령은 이미지를 레지스트리에 업로드하지 않습니다. 이미지는 레지스트리에 별도로 업로드해야 합니다. 다음 단계를 따르세요:

1. 이미지를 빌드합니다.
2. 이미지를 레지스트리에 push 합니다.

워크플로우는 다음과 같습니다:

```bash
docker build -t <repo-url>:<tag> .
docker push <repo-url>:<tag>
wandb launch -d <repo-url>:<tag>
```

Launch 에이전트는 지정된 컨테이너를 대상으로 하는 작업(job)을 실행합니다. 컨테이너 레지스트리에서 이미지를 pull할 수 있도록 에이전트 접근 권한을 구성하는 예시는 [Advanced agent setup](/ko/platform/launch/setup-agent-advanced/#agent-configuration)를 참고하세요.

Kubernetes의 경우, 이미지가 푸시된 레지스트리에 Kubernetes 클러스터의 파드가 접근할 수 있는지 확인하세요.
