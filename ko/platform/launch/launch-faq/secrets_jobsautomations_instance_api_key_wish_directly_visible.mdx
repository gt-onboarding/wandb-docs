---
title: 작업/자동화에 시크릿을 지정할 수 있나요? 예를 들어, 사용자에게 직접 보이지 않게 하고 싶은 API key가 있는 경우처럼요?
---

예, 다음 단계를 따르세요.

1. 다음 명령을 사용해 실행이 수행될 네임스페이스에 Kubernetes 시크릿을 만드세요:  
   `kubectl create secret -n <namespace> generic <secret_name> <secret_value>`

2. 시크릿을 생성한 후, 실행이 시작될 때 해당 시크릿이 주입되도록 큐를 구성하세요. 시크릿은 클러스터 관리자만 볼 수 있으며, 최종 사용자는 볼 수 없습니다.
