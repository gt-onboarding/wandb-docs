---
title: W&B Launch를 TensorFlow GPU와 함께 사용하려면 어떻게 해야 하나요?
---

GPU를 사용하는 TensorFlow 작업의 경우 컨테이너 빌드를 위해 사용자 지정 기본 이미지를 지정하세요. 이렇게 하면 실행 중에 GPU가 올바르게 활용됩니다. 리소스 구성의 `builder.accelerator.base_image` 키 아래에 이미지 태그를 추가하세요. 예를 들어:

```json
{
    "gpus": "all",
    "builder": {
        "accelerator": {
            "base_image": "tensorflow/tensorflow:latest-gpu"
        }
    }
}
```

W&amp;B 0.15.6 이전 버전에서는 `base_image`의 부모 키로 `accelerator` 대신 `cuda`를 사용하십시오.
