W&amp;B Launch 실험을 실행합니다.

```python
launch(
    api: Api,
    job: Optional[str] = None,
    entry_point: Optional[List[str]] = None,
    version: Optional[str] = None,
    name: Optional[str] = None,
    resource: Optional[str] = None,
    resource_args: Optional[Dict[str, Any]] = None,
    project: Optional[str] = None,
    entity: Optional[str] = None,
    docker_image: Optional[str] = None,
    config: Optional[Dict[str, Any]] = None,
    synchronous: Optional[bool] = (True),
    run_id: Optional[str] = None,
    repository: Optional[str] = None
) -> AbstractRun
```

| Arguments       | Description                                                                                                                                                                                                                                                 |
| :-------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `job`           | wandb.Job에 대한 문자열 참조. 예: wandb/test/my-job:latest                                                                                                                                                                                                           |
| `api`           | wandb.apis.internal의 wandb Api 인스턴스.                                                                                                                                                                                                                        |
| `entry_point`   | 프로젝트 내에서 실행할 엔트리 포인트. wandb URI의 경우 기본값은 원래 실행에서 사용된 엔트리 포인트이고, Git 저장소 URI의 경우 기본값은 main.py입니다.                                                                                                                                                            |
| `version`       | Git 기반 프로젝트의 경우, 커밋 해시 또는 브랜치 이름.                                                                                                                                                                                                                           |
| `name`          | 실행을 시작할 때 사용할 실행 이름.                                                                                                                                                                                                                                        |
| `resource`      | 실행에 사용할 실행 백엔드.                                                                                                                                                                                                                                             |
| `resource_args` | 원격 백엔드에서 실행을 시작하기 위한 리소스 관련 인자. 생성된 Launch 구성의 `resource_args` 키 아래에 저장됩니다.                                                                                                                                                                                 |
| `project`       | 실행을 전송할 대상 프로젝트                                                                                                                                                                                                                                             |
| `entity`        | 실행을 전송할 대상 엔터티                                                                                                                                                                                                                                              |
| `config`        | 실행에 대한 구성을 포함하는 딕셔너리. 또한 &quot;resource&#95;args&quot; 키 아래에 리소스별 인자를 포함할 수 있습니다.                                                                                                                                                                           |
| `synchronous`   | 실행이 완료될 때까지 대기할지 여부. 기본값은 True입니다. `synchronous`가 False이고 `backend`가 &quot;local-container&quot;인 경우, 이 메서드는 즉시 반환되지만 현재 프로세스는 로컬 실행이 완료될 때까지 종료 시 블록됩니다. 현재 프로세스가 중단되면, 이 메서드를 통해 비동기적으로 시작된 실행은 종료됩니다. `synchronous`가 True이고 실행이 실패하면 현재 프로세스도 에러가 발생합니다. |
| `run_id`        | 실행의 ID (:name: 필드를 최종적으로 대체하기 위한 값)                                                                                                                                                                                                                         |
| `repository`    | 원격 레지스트리를 위한 저장소 경로의 문자열 이름                                                                                                                                                                                                                                 |


<div id="example">
  #### 예시:
</div>

```python
from wandb.sdk.launch import launch

job = "wandb/jobs/Hello World:latest"
params = {"epochs": 5}
# W&B 프로젝트를 실행하고 로컬 호스트에서
# 재현 가능한 docker 환경을 생성합니다
api = wandb.apis.internal.Api()
launch(api, job, parameters=params)
```

| Returns                                                                                              | Description                                                        |
| :--------------------------------------------------------------------------------------------------- | :----------------------------------------------------------------- |
| an instance of`wandb.launch.SubmittedRun` exposing information (e.g. run ID) about the launched run. | 시작된 실행에 대한 정보(예: 실행 ID)를 제공하는 `wandb.launch.SubmittedRun` 인스턴스입니다. |

| Raises                                                                                | Description                                                            |
| :------------------------------------------------------------------------------------ | :--------------------------------------------------------------------- |
| `wandb.exceptions.ExecutionError` If a run launched in blocking mode is unsuccessful. | 블로킹 모드로 실행을 시작한 경우 실행이 실패하면 발생하는 `wandb.exceptions.ExecutionError`입니다. |
