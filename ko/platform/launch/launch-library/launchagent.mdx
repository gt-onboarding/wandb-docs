실행 대기열을 폴링하여 실행을 가져오고, wandb launch를 위해 실행을 시작하는 Launch 에이전트 클래스입니다.

```python
LaunchAgent(
    api: Api,
    config: Dict[str, Any]
)
```

| 인자       | 설명                           |
| :------- | :--------------------------- |
| `api`    | 백엔드에 요청을 보낼 때 사용할 API 객체입니다. |
| `config` | 에이전트 구성을 위한 config 딕셔너리입니다.  |

| 속성                       | 설명                               |
| :----------------------- | :------------------------------- |
| `num_running_jobs`       | 스케줄러를 제외한 실행 중인 작업 수를 반환합니다.     |
| `num_running_schedulers` | 스케줄러의 개수만 반환합니다.                 |
| `thread_ids`             | 에이전트에서 실행 중인 스레드 ID 키 목록을 반환합니다. |
