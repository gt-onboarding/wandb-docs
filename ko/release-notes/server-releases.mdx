이 페이지에서는 지원되는 W&amp;B Server 릴리스에 대한 릴리스 노트를 제공합니다.

<Update label="v0.77.1" description="2026년 1월 28일">
  **2026년 1월 28일**

  ## 변경 사항

  * 이제 **Self-Managed**에서 W&amp;B 워크스페이스에 Weave 패널을 추가하고, Weave 트레이스에서 W&amp;B 아티팩트를 참조할 수 있습니다. 이 기능은 이전에는 **Dedicated Cloud**에서만 사용할 수 있었습니다. 자세한 내용은 [Use Weave with W&amp;B training runs](/ko/weave/guides/tools/weave-in-workspaces)를 참조하세요.

  ## 수정 사항

  * 별칭(alias) 필터가 있을 때 레지스트리 버전 쿼리가 중복 항목을 반환할 수 있는 버그를 수정했습니다.
</Update>

<Update label="v0.77.0" description="2026년 1월 21일">
  **2026년 1월 21일**

  W&amp;B 0.77은 조직의 보안과 생산성을 강화하기 위한 보안 및 사용성 개선 사항을 도입합니다.

  이번 릴리스에는 API key 보안 강화, 단일 실행 및 다중 실행 워크스페이스 간 공유 구성을 통한 간편한 탐색, 새로운 선 그래프 음영 옵션, 미디어 패널 동기화 및 루핑의 정식 출시, 그리고 주요 편의성 개선 및 버그 수정이 포함되어 있습니다.

  ## 지원 및 서비스 종료

  * W&amp;B Server v0.65 이하 버전은 2026년 1월 30일에 지원이 종료됩니다.

  [릴리스 정책 및 프로세스](/ko/release-notes/release-policies)를 참조하세요. 도움이 필요하거나 문의 사항이 있으시면 [support](mailto:support@wandb.com)로 문의하세요.

  ## 예정된 변경 사항

  * 곧 Registry UI가 더 빠르게 탐색되고, 더 쉽게 살펴볼 수 있도록 개선될 예정입니다.

    * 향상된 자동 완성 검색, 새롭게 디자인된 Registry 및 Collection 카드, 그리고 새로운 Registry 아이콘을 통해 자산을 시각적으로 더 잘 구분할 수 있습니다. 초기에는 스마트 랭킹이 적용되며, 곧 AI 기반 랭킹이 제공될 예정입니다.
    * Registry 아이콘은 처음에는 자동 생성되며, 이후 언제든지 Registry Admin이 사용자 정의할 수 있습니다.

    이러한 업데이트는 다음 릴리스에 포함될 예정입니다. 자세한 내용은 [지원팀](mailto:support@wandb.com) 또는 담당 AISE에게 문의하세요.

  ## 보안

  * W&amp;B 전체에서 개인 계정과 서비스 계정 모두의 보안과 키 관리를 강화하기 위해 API key 관련 업데이트를 적용했습니다. 이러한 변경사항은 최신 보안 모범 사례를 따르면서도 팀이 더 높은 유연성과 더욱 안전한 자동화를 구현할 수 있도록 합니다.

    **중요한 내용**

    * API key는 한 번만 표시되므로, 생성 직후 즉시 복사해 저장해야 합니다.
    * 기존 키는 더 이상 복사할 수 없으며, 새 키를 생성해야 합니다.
    * 언제든지 키 이름을 변경하거나 삭제할 수 있습니다.
    * 서비스 계정은 이제 여러 개의 API key를 사용할 수 있습니다.

    [회원가입 및 API key 생성](/ko/models/quickstart#sign-up-and-create-an-api-key)을 참조하세요.

  ## 기능

  * **업데이트된 작업 공간 탐색.** 다중 실행 및 단일 실행 작업 공간 보기를 서로 일치하도록 통합했습니다. 이제 단일 실행으로 drill-down 하더라도, 다중 실행 보기에 대해 구성해 둔 것과 동일한 패널 레이아웃과 구성을 볼 수 있으며, 사용자 지정 차트, 레이아웃, 설정도 모두 그대로 유지됩니다. 이를 통해 동일한 맥락을 유지하고, 보기 구성을 다시 설정하는 수고를 줄일 수 있습니다. 탐색 버튼 위치 변경을 포함한 변경 사항은 이 [영상](https://www.loom.com/share/df232057aa2d4ee78026a4f9cf400499?sid=da3661eb-e8cd-4aa5-a666-db2c4091b02b)을 참고하세요.
    <Frame>
      ![업데이트된 워크스페이스 내비게이션을 보여주는 스크린샷](/images/release-notes/v0-77-0/workspace-navigation-update.png)
    </Frame>
  * 섹션 수준 [비디오 재생 동기화 및 반복](/ko/models/app/features/panels/media#sync) 기능은 정식으로 제공됩니다. 기본적으로 섹션 내 비디오는 동기화되어 재생됩니다.
  * 그룹화된 실행의 full-fidelity 선 플롯에서 이제 음영 영역이 **Min/Max**, **Standard Deviation**, **Standard Error** 또는 **None**을 표시하도록 구성할 수 있습니다. [Sampling](/ko/models/app/features/panels/line-plot/sampling)을 참조하세요.

  * 자동화를 더 효율적으로 설정할 수 있도록 이제 앱에서 기준으로 삼을 지표를 제안합니다.

  ### 레지스트리

  * Registry의 [아티팩트 라인리지 그래프](/ko/models/artifacts/explore-and-traverse-an-artifact-graph)에서 이제 항목을 드래그 앤 드롭으로 재배치하고 숨길 수 있습니다.
  * 아티팩트 버전을 조회할 때 이제 한 번에 새 레지스트리를 생성하고 해당 아티팩트 버전을 그 레지스트리에 연결할 수 있습니다.

  ### Weave

  * 이제 W&amp;B 앱에서 Weave 온보딩 페이지의 빈 상태 화면에 Python 예제 코드와 함께 TypeScript 예제 코드도 표시됩니다.
  * 이제 Weave 호출 로그는 기본적으로 연속 스크롤을 지원합니다. 이전에는 가장 최근 로그 10,000줄만 볼 수 있었습니다.
  * [Evaluation](/ko/weave/guides/core-types/evaluations) 비교 페이지의 막대 차트와 레이더 차트는 이제 크기 조정과 전체 화면 보기를 지원하며, 차트 영역 위에 마우스를 올리면 세부 정보가 담긴 툴팁이 표시됩니다.
  * [Weave Playground](https://wandb.ai/site/playground/)에는 새로운 모델이 포함되어 있습니다:
    * GPT 5.2
    * Grok 4.1
    * Opus 4.5
  * 이제 [Weave Playground](https://wandb.ai/site/playground/)에서 새 프롬프트를 생성하고 저장할 수 있습니다.

  ## 수정 사항

  * 실행의 **Notes** 텍스트 필드를 편집할 때 표시되는 너비가 지나치게 좁았던 버그를 수정했습니다. 이제 텍스트 상자는 보기 모드와 편집 모드에서 동일한 너비를 사용합니다.
  * W&amp;B Report를 PDF로 내보낼 때 포함된 이미지의 해상도가 너무 낮게 표시되던 문제를 수정했습니다.
  * Report의 선형 차트가 실행 선택기 변경 사항과 동기화해 업데이트되지 않을 수 있던 버그를 수정했습니다.
  * 리포트에서 이상치 숨기기 옵션이 없는 선 플롯(line plot)에 이상치가 표시되던 문제를 수정했습니다.
  * Report에서 여러 runset이 포함된 선 그래프에서, 서로 다른 runset에 속하지만 이름이 같은 실행의 데이터가 잘못 표시될 수 있던 버그를 수정했습니다. 이제 실행은 runset과 이름 조합으로 고유하게 식별됩니다.

  ### Weave

  * Dedicated Cloud 환경의 Weave UI에서 사용할 수 없는 W&amp;B Inference 링크가 표시되던 버그를 수정했습니다.
  * [Evaluation](/ko/weave/guides/core-types/evaluations) 비교 페이지에서 세부 정보 패널이 열려 있을 때 막대 차트가 너무 좁게 조정되던 버그를 수정했습니다.
  * [Weave Playground](https://wandb.ai/site/playground/)에서 입력할 때 커서가 화면의 표시 영역 밖으로 사라질 수 있던 UI 버그를 수정했습니다.
  * [Weave Playground](https://wandb.ai/site/playground/)에서 콜을 로드할 때 템플릿 변수를 편집할 수 없던 버그를 수정했습니다.
  * [Evaluation](/ko/weave/guides/core-types/evaluations) 개요 페이지에서 하위 trace의 상세 보기로 이동할 때 operation selector가 설정되지 않는 버그를 수정했습니다. 이로 인해 어떤 trace가 선택되어 있는지 파악하기 어려웠고, 일부 열이 비어 있는 것처럼 표시되는 문제가 발생했습니다.
  * [Evaluation](/ko/weave/guides/core-types/evaluations) 비교 보기 페이지에서 **Delete**를 클릭해도 비교 보기가 실제로 삭제되지 않는 문제를 수정했습니다.
  * 사용자 정의 타입을 사용하는 [Evaluation](/ko/weave/guides/core-types/evaluations) 결과에서, 사용자 정의 타입 대신 `CellValue` 필드가 빈 값으로 표시되던 버그를 수정했습니다.
  * 왼쪽에 고정된 셀이 **runs as rows** 표시 모드에서 투명하게 표시될 수 있던 버그를 수정했습니다.
</Update>

  ## Fixes

  * 워크스페이스에서 리포트로 선 그래프(line plot)를 가져올 때, 그래프에서 극단적 이상치를 숨긴 경우 가져오기가 멈출 수 있던 버그를 수정했습니다.
  * 테이블 패널의 높이를 줄였을 때, 패널이 올바르게 크기 조정되지 않을 수 있던 버그를 수정했습니다.
  * 마스크 오버레이가 캡션이 있는 이미지 영역을 넘어서 표시될 수 있던 버그를 수정했습니다.
  * 실행 노트(run note)의 편집 상자 크기가 편집하기에 너무 좁았던 버그를 수정했습니다. 이제 편집 상자는 표시 모드의 텍스트와 동일한 크기를 사용합니다.
  * Organization Dashboard에서 **Service Accounts** 탭을 클릭하면 페이지가 충돌할 수 있던 버그를 수정했습니다.
  * 실행 로그를 보고 있을 때 실행 간 전환 시, 잘못된 실행의 로그가 표시될 수 있던 캐싱 버그를 수정했습니다.
  * 클라이언트가 GraphQL 작업을 취소하는 경우, 이제 `5xx` HTTP 서버 오류가 아닌 `4xx` HTTP 클라이언트 오류로 올바르게 보고됩니다.
</Update>

<Update label="v0.76.0" description="2025년 11월 20일">
  **2025년 11월 20일**

  W&amp;B v0.76은 더 스마트한 미디어 도구, 간소화된 워크플로우, 강력한 새 인터페이스를 도입하여 실험 인사이트와 생산성을 크게 향상시킵니다. 자동 재생 및 반복 재생을 지원하는 멀티 비디오 동기화로 빠른 나란히 비교 평가가 가능하며, 간소화된 워크스페이스 탐색으로 뷰 간 이동이 더욱 원활해집니다. 또한 새로운 LEET 터미널 UI를 통해 실행 인사이트를 커맨드라인에서 빠르고 실시간으로 확인할 수 있습니다.

  ## 지원 및 서비스 종료

  * W&amp;B Server v0.63 및 그 이전 버전은 2025년 11월 20일부로 지원이 종료되었습니다(EOL).
  * W&amp;B Server v0.65는 2026년 1월 30일부로 지원 종료(EOL)될 예정입니다.

  ## 기능

  * **멀티 비디오 동기화**: 여러 비디오 패널을 동시에 재생하고 제어하여 학습 실행 간 정성적 평가 및 비교, 다양한 실험에서의 모델 동작 분석, 멀티모달 모델 체크포인트 평가에 활용할 수 있습니다.

    동기화된 비디오 재생을 사용하면 여러 비디오를 동시에 재생·일시 정지·스크럽하고 속도를 조절할 수 있어, 스타일, 타이밍, 모션 등 다양한 요소를 빠르게 시각적으로 품질 검수하고 평가할 수 있는 진정한 나란히 비교가 가능합니다.

    <Frame>
      ![비디오 재생 동기화 데모 애니메이션](/images/release-notes/v0-76-0/video_playback_sync_demo.gif)
    </Frame>

    사용해 보려면 **Settings** → **Media**로 이동하세요. 현재 Dedicated Cloud 전용으로 제공됩니다.

  ## 기능

  * **레지스트리 접근 제어 업데이트:**
    * **프로그래밍 방식 레지스트리 액세스 제어:** [레지스트리 역할](/ko/models/registry/configure_registry#details-about-registry-roles)이 이제 SCIM 스키마에 포함되었습니다. 사용자를 [생성](/ko/platform/hosting/iam/scim#create-user)하거나 업데이트할 때 해당 사용자의 레지스트리 역할을 구성할 수 있으며, 사용자를 [조회](/ko/platform/hosting/iam/scim#get-user)하면 레지스트리 역할 정보가 함께 반환됩니다.
    * **레지스트리 액세스 제한:** 전체 레지스트리 액세스를 부여하지 않으려는 경우, 새 레지스트리 역할인 [Restricted Viewer](/ko/models/registry/configure_registry)를 부여할 수 있습니다. 이 역할은 컬렉션, 자동화 또는 기타 레지스트리 리소스를 생성, 업데이트, 삭제할 수 있는 권한 없이 레지스트리 아티팩트에 대한 읽기 전용 액세스를 제공합니다. 이는 민감하거나 규제를 받는 레지스트리 콘텐츠에 유용합니다.
    * [**확장된 레지스트리 액세스:**](https://wandb.ai/wandb_fc/product-announcements-fc/reports/Registry-for-W-B-Models-viewers-Faster-discovery-cleaner-handoffs--VmlldzoxNDc4MzM5Mg) 이제 Models **Viewer** 역할이 있는 모든 사용자는 기본적으로 전체 레지스트리 **Member**이므로, 모델과 아티팩트를 기본 설정만으로 탐색, 비교, 사용할 수 있습니다. Models **Viewer**는 **Restricted Viewer**, **Viewer**, **Admin**과 같은 다른 레지스트리 역할로 할당될 수 있습니다. 이를 통해 조직 내 모든 사용자가 레지스트리의 전체 가치를 활용할 수 있습니다.

  * **즐겨찾는 Registry:** 규모가 커질수록 Registry를 더 쉽게 탐색할 수 있도록 이제 Registry를 즐겨찾기로 표시할 수 있습니다. Registry 랜딩 페이지에서 Registry 카드에 마우스를 올린 뒤 별 윤곽 아이콘을 클릭하세요. 개별 Registry 페이지에서는 페이지 상단의 별 윤곽 아이콘을 클릭하세요. 즐겨찾는 Registry는 Registry 랜딩 페이지 상단에 알파벳 순으로 표시됩니다.

    ![즐겨찾는 레지스트리](/images/release-notes/v0-75-0/starred-registries.png)

  * **자동화 실행 기록:** **Automation history** 탭에서 프로젝트 또는 레지스트리 [Automations](/ko/models/automations/automation-events)의 실행 기록을 확인할 수 있습니다. 모든 자동화 실행은 상태와 주요 상세 정보를 한눈에 파악할 수 있도록 최신순으로 표시됩니다. 자동화를 이해하고 디버깅할 수 있도록, 자세히 보기에서는 실행의 조건, 작업, 결과가 상세히 표시됩니다.

  ## 수정 사항

  * 이제 워크스페이스나 섹션에서 모든 플롯에 대해 **원본 표시** 선 그래프 설정을 켜거나 끌 수 있습니다.
  * Reports에서 실행 선택기에서 모든 열을 고정하면 보고서 레이아웃이 깨지던 버그를 수정했습니다.
  * 실행 선택기의 경계를 넘어 확장될 수 있던 고정 열 관련 버그를 수정했습니다.
  * **Notes** 필드를 편집하는 동시에 실행 이름을 변경하면 실행 이름 변경이 원래대로 되돌아가던 버그를 수정했습니다.
  * X축을 **Relative Wall Time**으로 설정한 상태에서 그룹화된 실행을 그래프로 그릴 때 잘못된 값이 표시되던 버그를 수정했습니다.

    더 강력한 새로운 환경으로 원활하게 전환하실 수 있도록 최적화를 진행하고 있습니다. 마이그레이션과 관련해 궁금한 점이 있으시면 W&amp;B 계정 팀이나 [support](mailto:support@wandb.ai)로 문의하세요.

  ## 기능

  * <a id="registry_ga_announcement" aria-label="W&B Registry GA 공지" /> W&amp;B는 향후 여러 차례의 릴리스에 걸쳐 기존 팀 수준 Model Registry를 W&amp;B Registry로 단계적으로 마이그레이션할 예정입니다. **사용자 측에서 별도로 취해야 할 작업은 없습니다. W&amp;B가 각 팀의 Model Registry 자산을 해당 팀에 대해 자동으로 생성되는 팀 수준 비공개 레지스트리로 자동 복사합니다.** 기존 팀 수준 Model Registry에서 모델 컬렉션을 참조하던 링크는 계속 정상적으로 동작합니다.

    1. Server v0.71(이번 릴리스)에서는 이제 모든 조직에서 Registry가 기본값으로 활성화됩니다.
    2. Server v0.73(8월)에는 업그레이드 중에 이 마이그레이션을 자동으로 실행하는 옵트아웃용 환경 변수가 포함될 예정입니다. 대부분의 조직에서 마이그레이션에는 5~30분이 소요됩니다. 마이그레이션 중에는 기존 팀의 Model Registry 또는 새 Registry에 아티팩트를 연결하려는 작업이 오류가 발생하며 실패합니다. **아티팩트 로깅과 조회에는 영향이 없습니다**.
    3. Server v0.74(9월)에서는 이 플래그가 제거되며, 업그레이드 중에 마이그레이션이 수행됩니다.

    우리는 사용자의 불편을 최소화하면서 강력한 새로운 환경으로 원활하게 업그레이드할 수 있도록 최적화하고 있습니다. 마이그레이션과 관련해 궁금한 점이 있다면 언제든지 W&amp;B로 문의하세요.
  * 이제 아티팩트에 태그를 추가하면 자동화를 트리거할 수 있습니다. [아티팩트 이벤트](/ko/models/automations/automation-events/#artifact-events)를 참고하세요.
  * 패널을 전체 화면으로 볼 때는 섹션 내의 이전/다음 패널로 이동하기 위해 **Previous** 및 **Next** 버튼이나 키보드의 왼쪽 및 오른쪽 화살표 키를 사용하세요.
  * 전체 화면에서 미디어 패널을 볼 때는 macOS에서는 **CMD + 왼쪽 또는 오른쪽 화살표** 키를, Windows/Linux에서는 **Ctrl + 왼쪽 또는 오른쪽 화살표** 키를 사용해 스텝 슬라이더를 이동합니다.
  * 이제 동일한 단계 슬라이더 키를 사용하는 미디어 패널을 동기화할 수 있습니다. 한 미디어 패널에서 단계 슬라이더를 이동하면 다른 패널의 단계 슬라이더도 함께 이동합니다. 워크스페이스 또는 섹션 설정을 열고 **Media**로 이동한 다음 **Sync** 탭을 클릭하고 **Sync slider by key (Step)**를 켭니다.

  ## 성능

  * 대형 워크스페이스에서 특히 많은 워크스페이스 상호작용의 성능이 개선되었습니다. 예를 들어 섹션을 펼치거나 실행 선택기를 사용할 때 반응 속도가 눈에 띄게 빨라졌습니다.
  * Fork 및 Rewind 성능 개선.

    실행을 [Forking](/ko/models/runs/forking)하면 기존 실행과 동일한 구성으로 새 실행이 생성됩니다. 포크된 실행에 대한 변경 사항은 부모 실행에는 영향을 주지 않으며, 그 반대도 마찬가지입니다. 포크된 실행과 부모 실행 사이에는 포인터가 유지됩니다. 실행을 [Rewinding](/ko/models/runs/rewind)하면 기존 데이터를 잃지 않고 해당 시점부터 새로운 데이터를 기록할 수 있습니다.

    중첩된 포크가 많은 프로젝트에서 캐싱이 개선되어, 이제 새로운 실행을 포크하는 작업이 훨씬 더 효율적입니다.
