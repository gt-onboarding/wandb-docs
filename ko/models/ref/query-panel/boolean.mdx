  ## 연결 가능한 op
</div>

### <a id="and"></a>`and`

두 값의 논리 `AND` 결과를 반환합니다

| 인자 | 설명 |
| :--- | :--- |
| `lhs` | 첫 번째 불리언 값 |
| `rhs` | 두 번째 불리언 값 |

#### 반환값

두 값에 대한 논리적 `and` 연산 결과

### <a id="or"></a>`or`

두 값에 대한 논리적 `or` 연산 결과를 반환합니다

| Argument | Description |
| :--- | :--- |
| `lhs` | 첫 번째 이진 값 |
| `rhs` | 두 번째 이진 값 |

#### 반환 값

두 값을 논리적으로 `or`한 결과

### <a id="boolean-not"></a>`boolean-not`

값의 논리 부정을 반환합니다.

| Argument | Description |
| :--- | :--- |
| `bool` | 불리언 값입니다. |

#### 반환 값

해당 값의 논리 부정

### <a id="boolean-not"></a>`boolean-not`

입력 값의 논리 부정 결과를 반환합니다

| 인수 | 설명 |
| :--- | :--- |
| `bool` | 불리언 값 |

#### 반환 값

해당 값의 논리 부정값
