### <a id="project-artifact" />`project-artifact`

| Argument | Description |
| :--- | :--- |
| `project` | [프로젝트](/ko/models/ref/query-panel/project/) |
| `artifactName` | [아티팩트](/ko/models/ref/query-panel/artifact/)의 이름 |

#### 반환 값

[project](/ko/models/ref/query-panel/project/) 내에서 지정된 이름을 가진 [artifact](/ko/models/ref/query-panel/artifact/)
