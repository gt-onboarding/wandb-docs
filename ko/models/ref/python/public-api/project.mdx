## <kbd>class</kbd> `Project`

프로젝트는 실행을 위한 네임스페이스입니다.

### <kbd>method</kbd> `Project.__init__`

```python
__init__(
    client: 'RetryingClient',
    entity: 'str',
    project: 'str',
    attrs: 'Mapping[str, Any]'
) → Project
```

**Args:**

* `client`:  W&amp;B API 클라이언트 인스턴스.
* `name` (str):  프로젝트 이름.
* `entity` (str):  프로젝트를 소유하는 엔터티 이름.

엔터티에 속한 단일 프로젝트입니다.

**Args:**

* `client`:  W&amp;B를 조회하는 데 사용하는 API 클라이언트.
* `entity`:  프로젝트를 소유하는 엔터티.
* `project`:  조회할 프로젝트의 이름.
* `attrs`:  프로젝트의 속성.
