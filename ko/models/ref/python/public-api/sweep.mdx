## <kbd>class</kbd> `Sweep`

스윕과 관련된 실행들의 집합입니다. 

**속성:**

- `runs` (Runs):  실행 목록 
 - `id` (str):  스윕 ID 
 - `project` (str):  스윕이 속한 프로젝트의 이름 
 - `config` (dict):  스윕 설정을 포함하는 딕셔너리 
 - `state` (str):  스윕의 상태. "Finished", "Failed", "Crashed", "Running" 중 하나일 수 있습니다. 
 - `expected_run_count` (int):  스윕에 대해 예상되는 실행 수입니다.

### <kbd>property</kbd> Sweep.expected_run_count

스윕에서 예상되는 실행 수를 반환하고, 실행 횟수가 무한대인 경우 None을 반환합니다.

- `int | None`: expected_run_count 프로퍼티의 값.

### <kbd>property</kbd> Sweep.name

Sweep의 이름입니다. 

다음 우선순위에 따라, 처음으로 존재하는 이름을 반환합니다: 

1. 사용자가 수정한 표시 이름 2. 생성 시 설정된 이름 3. Sweep ID 

---

### <kbd>property</kbd> Sweep.order

Sweep의 순서 키를 반환합니다. 

---

### <kbd>property</kbd> Sweep.path

프로젝트의 경로(path)를 반환합니다. 

path는 엔터티, 프로젝트 이름, sweep ID로 구성된 리스트입니다. 

---

### <kbd>property</kbd> Sweep.url

sweep의 URL입니다. 

sweep URL은 엔터티, 프로젝트, 문자열 "sweeps", 그리고 sweep ID.run_id로부터 생성됩니다. SaaS 사용자의 경우 `https://wandb.ai/entity/project/sweeps/sweeps_ID` 형태입니다. 

---

### <kbd>property</kbd> Sweep.username

* `query`:  쿼리 실행에 사용할 쿼리.
