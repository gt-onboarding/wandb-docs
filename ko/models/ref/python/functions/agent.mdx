### <kbd>function</kbd> `agent`

```python
agent(
    sweep_id: str,
    function: Optional[Callable] = None,
    entity: Optional[str] = None,
    project: Optional[str] = None,
    count: Optional[int] = None,
    forward_signals: bool = False
) → None
```

하나 이상의 스윕 에이전트를 시작합니다.

스윕 에이전트는 어떤 스윕에 속하는지, 어떤 함수를 실행할지, 그리고 (선택적으로) 몇 개의 에이전트를 실행할지를 알기 위해 `sweep_id`를 사용합니다.

**Args:**

* `sweep_id`:  스윕에 대한 고유 식별자입니다. 스윕 ID는 W&amp;B CLI 또는 Python SDK에 의해 생성됩니다.
* `function`:  스윕 설정에서 지정된 &quot;program&quot;(프로그램) 대신 호출할 함수입니다.
* `entity`:  스윕으로 생성된 W&amp;B 실행을 전송할 사용자 이름 또는 팀 이름입니다. 지정한 엔터티가 이미 존재하는지 확인하세요. 엔터티를 지정하지 않으면 실행은 기본 엔터티(일반적으로 사용자 이름)로 전송됩니다.
* `project`:  스윕으로 생성된 W&amp;B 실행이 전송될 프로젝트 이름입니다. 프로젝트가 지정되지 않으면 실행은 &quot;Uncategorized&quot;라는 레이블의 프로젝트로 전송됩니다.
* `count`:  스윕 설정에서 시도할 trial 수입니다.
* `forward_signals`:  에이전트가 수신한 신호를 자식 프로세스로 전달할지 여부입니다. CLI 에이전트에서만 지원됩니다.
