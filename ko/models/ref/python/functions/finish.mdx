### <kbd>function</kbd> `finish`

```python
finish(exit_code: 'int | None' = None, quiet: 'bool | None' = None) → None
```

실행을 종료하고 남아 있는 데이터를 모두 업로드합니다.

W&amp;B 실행이 완료되었음을 표시하고 모든 데이터가 서버와 동기화되도록 보장합니다. 실행의 최종 상태는 종료 조건과 동기화 상태에 따라 결정됩니다.

실행 상태:

* Running: 데이터를 기록하거나 하트비트(heartbeat)를 전송하고 있는 활성 실행입니다.
* Crashed: 하트비트 전송이 예기치 않게 중단된 실행입니다.
* Finished: 모든 데이터가 동기화된 상태에서 (`exit_code=0`) 정상적으로 완료된 실행입니다.
* Failed: 오류가 발생한 상태로 완료된 실행입니다 (`exit_code!=0`).

**인자(Args):**

* `exit_code`:  실행의 종료 코드를 나타내는 정수입니다. 성공 시 0을 사용하고, 그 외의 값은 실행이 실패했음을 의미합니다.
* `quiet`:  더 이상 사용되지 않는 인자입니다(Deprecated). `wandb.Settings(quiet=...)`를 사용해 로깅 상세 수준을 설정하세요.
