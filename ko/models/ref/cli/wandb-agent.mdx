W&amp;B 에이전트를 실행합니다.


<div id="usage">
  ## 사용 방법
</div>

```bash
wandb agent SWEEP_ID [OPTIONS]
```


<div id="arguments">
  ## 인수
</div>

| 인수 | 설명 | 필수 여부 |
| :--- | :--- | :--- |
| `SWEEP_ID` | 사용 가능한 설명이 없습니다 | 예 |

<div id="options">
  ## 옵션
</div>

| 옵션 | 설명 |
| :--- | :--- |
| `--project`, `-p` | 스윕에서 생성된 W&B 실행을 보낼 프로젝트의 이름입니다. 프로젝트를 지정하지 않으면 실행은 'Uncategorized'라는 레이블이 붙은 프로젝트로 전송됩니다. |
| `--entity`, `-e` | 스윕에서 생성된 W&B 실행을 보낼 사용자 이름 또는 팀 이름입니다. 지정한 엔터티가 이미 존재하는지 확인하세요. 엔터티를 지정하지 않으면 실행은 기본 엔터티(일반적으로 본인 사용자 이름)로 전송됩니다. |
| `--count` | 이 에이전트가 실행할 실행의 최대 개수입니다. |
| `--forward-signals`, `-f` | 에이전트에 전달된 시그널(예: SIGINT/SIGTERM)을 하위 실행으로 전달하여 하위 실행이 정상적으로 종료될 수 있도록 합니다. (기본값: False) |
