W&amp;B Job을 실행하거나 대기열에 추가합니다. 자세한 내용은 https://wandb.me/launch를 참고하세요.


<div id="usage">
  ## 사용 방법
</div>

```bash
wandb launch [OPTIONS]
```


<div id="options">
  ## 옵션
</div>

| Option | Description |
| :--- | :--- |
| `--uri`, `-u` | 실행할 로컬 경로 또는 Git 저장소 URI입니다. 이 옵션을 제공하면 지정한 URI에서 job을 생성합니다. |
| `--job`, `-j` | 실행할 job의 이름입니다. 이 값을 지정하면 launch 명령에 URI가 필요하지 않습니다. |
| `--entry-point`, `-E` | 프로젝트 내 엔트리 포인트입니다. [기본값: main]. 엔트리 포인트를 찾지 못하면, 지정된 이름의 프로젝트 파일을 스크립트로 실행하려고 시도하며, `.py` 파일은 `python`으로, `.sh` 파일은 기본 셸(환경 변수 `$SHELL`로 지정됨)로 실행합니다. 이 값을 지정하면, 설정 파일을 통해 전달된 entrypoint 값을 덮어씁니다. |
| `--build-context` | 소스 코드 내 build context의 경로입니다. 기본값은 소스 코드의 루트입니다. `-u` 옵션과만 호환됩니다. |
| `--name` | 실행을 시작할 때 사용할 실행 이름입니다. 지정하지 않으면 무작위 실행 이름이 사용됩니다. 이 값을 지정하면, 설정 파일을 통해 전달된 name 값을 덮어씁니다. |
| `--entity`, `-e` | 새 실행을 전송할 대상 엔터티의 이름입니다. 기본값은 로컬 `wandb/settings` 폴더에 설정된 엔터티입니다. 이 값을 지정하면, 설정 파일을 통해 전달된 entity 값을 덮어씁니다. |
| `--project`, `-p` | 새 실행을 전송할 대상 프로젝트의 이름입니다. 기본값은 소스 URI에서 주어진 프로젝트 이름이거나, GitHub 실행의 경우 Git 저장소 이름입니다. 이 값을 지정하면, 설정 파일을 통해 전달된 project 값을 덮어씁니다. |
| `--resource`, `-r` | 실행에 사용할 실행 리소스입니다. 지원되는 값: `local-process`, `local-container`, `kubernetes`, `sagemaker`, `gcp-vertex`. 리소스 구성이 없는 큐로 push할 때는 이제 필수 매개변수입니다. 이 값을 지정하면, 설정 파일을 통해 전달된 resource 값을 덮어씁니다. |
| `--docker-image`, `-d` | 사용하려는 특정 Docker 이미지입니다. `name:tag` 형식으로 지정합니다. 이 값을 지정하면, 설정 파일을 통해 전달된 Docker 이미지 값을 덮어씁니다. |
| `--base-image`, `-B` | job 코드를 실행할 Docker 이미지입니다. `--docker-image`와는 호환되지 않습니다. |
| `--config`, `-c` | launch config로 전달할 JSON 파일 경로(`.json` 확장자로 끝나야 함) 또는 JSON 문자열입니다. 실행이 어떻게 구성될지에 대한 설정을 정의합니다. |
| `--set-var`, `-v` | allow listing이 활성화된 큐용 템플릿 변수 값을 key=value 형식의 key-value 쌍으로 설정합니다. 예: `--set-var key1=value1 --set-var key2=value2` |
| `--queue`, `-q` | push할 실행 큐의 이름입니다. 지정하지 않으면 단일 실행을 바로 실행합니다. 인자 없이 제공된 경우(`--queue`), 기본 큐 `default`가 사용됩니다. 이름을 제공한 경우, 해당 실행 큐는 지정된 프로젝트와 엔터티 하에 존재해야 합니다. |
| `--async` | job을 비동기적으로 실행하는 플래그입니다. 기본값은 false입니다. 즉, `--async`를 설정하지 않으면 `wandb launch`는 job이 완료될 때까지 대기합니다. 이 옵션은 `--queue`와 호환되지 않습니다. agent와 함께 실행할 때의 비동기 옵션은 `wandb launch-agent`에서 설정해야 합니다. (기본값: False) |
| `--resource-args`, `-R` | 컴퓨트 리소스에 resource args로 전달할 JSON 파일 경로(`.json` 확장자로 끝나야 함) 또는 JSON 문자열입니다. 제공해야 하는 정확한 내용은 실행 백엔드마다 다릅니다. 이 파일의 레이아웃은 문서를 참고하세요. |
| `--dockerfile`, `-D` | job을 빌드하는 데 사용되는 Dockerfile의 경로입니다. job의 루트를 기준으로 한 상대 경로입니다. |
| `--priority`, `-P` | `--queue`가 전달된 경우, job의 우선순위를 설정합니다. 우선순위가 높은 launch job이 먼저 처리됩니다. 우선순위는 높은 순서부터 낮은 순서까지 다음과 같습니다: `critical`, `high`, `medium`, `low` |
