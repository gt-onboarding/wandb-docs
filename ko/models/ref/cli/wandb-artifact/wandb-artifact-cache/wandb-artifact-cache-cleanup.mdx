<div id="usage">
  ## 사용 방법
</div>

```bash
wandb artifact cache cleanup TARGET_SIZE [OPTIONS]
```


<div id="arguments">
  ## 인수
</div>

| 인수 | 설명 | 필수 여부 |
| :--- | :--- | :--- |
| `TARGET_SIZE` | 설명이 제공되지 않습니다 | 예 |

<div id="options">
  ## 옵션
</div>

| 옵션 | 설명 |
| :--- | :--- |
| `--remove-temp` | 임시 파일을 제거합니다 (기본값: False) |
