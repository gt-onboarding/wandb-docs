아티팩트를 wandb에 업로드하기


<div id="usage">
  ## 사용 방법
</div>

```bash
wandb artifact put PATH [OPTIONS]
```


<div id="arguments">
  ## 인수
</div>

| 인수 | 설명 | 필수 여부 |
| :--- | :--- | :--- |
| `PATH` | 설명이 제공되지 않습니다 | 예 |

<div id="options">
  ## 옵션
</div>

| 옵션 | 설명 |
| :--- | :--- |
| `--name`, `-n` | 푸시할 아티팩트의 이름: project/artifact_name |
| `--description`, `-d` | 이 아티팩트에 대한 설명 |
| `--type`, `-t` | 아티팩트의 유형 (기본값: dataset) |
| `--alias`, `-a` | 이 아티팩트에 적용할 별칭 (기본값: ['latest']) |
| `--id` | 업로드할 실행의 ID입니다. |
| `--resume` | 현재 디렉터리에서 마지막 실행을 재개합니다. |
| `--skip_cache` | 아티팩트 파일을 업로드할 때 캐시를 사용하지 않습니다. (기본값: False) |
| `--policy` | 아티팩트 파일을 업로드할 때 사용할 스토리지 정책을 설정합니다. (기본값: mutable) |
