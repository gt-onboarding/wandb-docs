아래 버튼을 클릭하여 MNIST 데이터에 대한 PyTorch Quickstart 예제 프로젝트를 실행해 보세요.

<div id="1-log-a-table">
  ## 1. Log a table
</div>

W&amp;B에 테이블을 로깅합니다. 새 테이블을 생성하거나 Pandas DataFrame을 전달할 수 있습니다.

<Tabs>
  <Tab title="테이블 생성">
    새 `Table` 객체를 생성하고 로깅하려면 다음을 사용합니다:

    * [`wandb.init()`](/ko/models/ref/python/functions/init): 결과를 추적할 [실행](/ko/models/runs/)을 생성합니다.
    * [`wandb.Table()`](/ko/models/ref/python/data-types/table): 새 테이블 객체를 생성합니다.
      * `columns`: 열 이름을 설정합니다.
      * `data`: 각 행의 내용을 설정합니다.
    * [`wandb.Run.log()`](/ko/models/ref/python/experiments/run.md/#method-runlog): 테이블을 로깅해 W&amp;B에 저장합니다.

    예시는 다음과 같습니다:

    ```python
    import wandb

    with wandb.init(project="table-test") as run:
        # 새 테이블을 생성하고 로깅합니다.
        my_table = wandb.Table(columns=["a", "b"], data=[["a1", "b1"], ["a2", "b2"]])
        run.log({"Table Name": my_table})
    ```
  </Tab>

  <Tab title="Pandas Dataframe">
    Pandas DataFrame을 `wandb.Table()`에 전달하여 새 테이블을 생성합니다.

    ```python
    import wandb
    import pandas as pd

    df = pd.read_csv("my_data.csv")

    with wandb.init(project="df-table") as run:
        # DataFrame으로부터 새 테이블을 생성하고
        # 이를 W&B에 로깅합니다.
      my_table = wandb.Table(dataframe=df)
      run.log({"Table Name": my_table})
    ```

    지원되는 데이터 타입에 대한 자세한 내용은 W&amp;B API Reference 가이드의 [`wandb.Table`](/ko/models/ref/python/data-types/table)를 참조하세요.
  </Tab>
</Tabs>
