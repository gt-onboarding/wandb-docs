W&amp;B Sweeps를 사용해 하이퍼파라미터 탐색을 자동화하고, 풍부하고 대화형으로 실험 추적 결과를 시각화하세요. 베이즈, 그리드 서치, 랜덤 서치와 같은 널리 쓰이는 탐색 방법을 선택해 하이퍼파라미터 공간을 탐색할 수 있습니다. 하나 이상의 머신에서 스윕을 확장하고 병렬로 실행하세요.

<div id="how-it-works">
  ### 동작 방식
</div>

두 가지 [W&amp;B CLI](/ko/models/ref/cli/) 명령으로 스윕을 생성합니다:

1. 스윕을 초기화합니다.

```bash
  wandb sweep --project <project-name> <path-to-config file>
```

2. 스윕 에이전트를 실행합니다.

```bash
  wandb agent <sweep-ID>
```

<Note>
  앞의 코드 스니펫과 이 페이지에서 제공하는 Colab 노트북은 W&amp;B CLI로 스윕을 초기화하고 생성하는 방법을 보여줍니다. Python SDK를 사용해 스윕을 구성, 초기화 및 실행하는 방법은 [Sweeps walkthrough](/ko/models/sweeps/walkthrough/)를 참고하세요.
</Note>
