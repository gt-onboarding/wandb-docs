---
title: 레지스트리 생성
---

레지스트리는 사용할 수 있는 아티팩트 타입을 유연하게 제어할 수 있게 해 주고, 레지스트리의 공개 범위를 제한하는 등 다양한 기능을 제공합니다.

<div id="create-a-registry">
  ## 레지스트리 생성
</div>

W&amp;B Registry UI 또는 W&amp;B Python SDK를 사용하여 프로그래밍 방식으로 레지스트리를 생성할 수 있습니다.

<Tabs>
  <Tab title=" W&B Registry UI">
    1. https://wandb.ai/registry/ 에서 W&amp;B Registry로 이동합니다.
    2. **Create registry** 버튼을 클릭합니다.
    3. **Name** 필드에 레지스트리 이름을 입력합니다.
    4. 필요하면 레지스트리에 대한 설명을 입력합니다.
    5. **Registry visibility** 드롭다운에서 레지스트리를 볼 수 있는 사용자를 선택합니다. 레지스트리 가시성 옵션에 대한 자세한 내용은 [Registry visibility types](./configure_registry#registry-visibility-types)를 참고하세요.
    6. **Accepted artifacts type** 드롭다운에서 **All types** 또는 **Specify types** 중 하나를 선택합니다.
    7. (**Specify types** 를 선택한 경우) 레지스트리가 허용할 하나 이상의 아티팩트 유형을 추가합니다.
    8. **Create registry** 버튼을 클릭합니다.
  </Tab>

  <Tab title="Python SDK">
    [`wandb.Api().create_registry()`](/ko/models/ref/python/#method-apicreate_registry) 메서드를 사용해 프로그래밍 방식으로 레지스트리를 생성합니다. `name` 및 `visibility` 매개변수에 레지스트리의 이름과 레지스트리 [visibility](#visibility-types)를 각각 지정합니다.

    아래 코드 블록을 복사해 붙여넣고, `<>` 로 둘러싸인 값을 사용자 값으로 교체하세요:

    ```python
    import wandb

    registry = wandb.Api().create_registry(
        name="<registry_name>",
        visibility="< 'restricted' | 'organization' >",
    )
    ```

    레지스트리를 생성할 때 지정할 수 있는 전체 매개변수 목록은 [`wandb.Api().create_registry()`](/ko/models/ref/python/#method-apicreate_registry) 메서드 레퍼런스를 참고하세요.
  </Tab>
</Tabs>

<Note>
  아티팩트 유형은 한 번 레지스트리 설정에 저장되면 레지스트리에서 제거할 수 없습니다.
</Note>

예를 들어, 다음 이미지는 사용자가 생성하려는 `Fine_Tuned_Models`라는 레지스트리를 보여줍니다. 이 레지스트리는 레지스트리에 수동으로 추가된 구성원만 접근할 수 있도록 **Restricted** 로 설정되어 있습니다.

<div id="visibility-types">
  ## 가시성 유형
</div>

레지스트리의 *가시성(visibility)*은 해당 레지스트리에 누가 접근할 수 있는지를 결정합니다. 레지스트리의 가시성을 제한하면 지정한 멤버만 해당 레지스트리에 접근하도록 보장할 수 있습니다.

레지스트리 가시성에는 두 가지 옵션이 있습니다:

| Visibility | Description |
| --- | --- |
| Restricted   | 초대된 조직 구성원만 레지스트리에 접근할 수 있습니다.|
| Organization | 조직의 모든 사용자가 레지스트리에 접근할 수 있습니다. |

팀 관리자 또는 레지스트리 관리자가 레지스트리의 가시성을 설정할 수 있습니다.

*Restricted* 가시성으로 레지스트리를 생성한 사용자는 해당 레지스트리의 레지스트리 관리자로 자동 추가됩니다.

<div id="configure-the-visibility-of-a-registry">
  ## 레지스트리 공개 범위 설정
</div>

팀 관리자 또는 레지스트리 관리자는 레지스트리를 생성하는 중이거나 생성한 후에 레지스트리의 공개 범위를 지정할 수 있습니다.

기존 레지스트리의 공개 범위를 제한하려면 다음을 수행하세요:

1. https://wandb.ai/registry/ 에서 W&amp;B Registry로 이동합니다.
2. 레지스트리를 선택합니다.
3. 오른쪽 상단 모서리의 기어 아이콘을 클릭합니다.
4. **Registry visibility** 드롭다운 목록에서 원하는 레지스트리 공개 범위를 선택합니다.
5. **Restricted visibility**를 선택한 경우:
   1. 이 레지스트리에 접근할 수 있도록 허용할 조직 구성원을 추가합니다. **Registry members and roles** 섹션으로 스크롤한 후 **Add member** 버튼을 클릭합니다.
   2. **Member** 필드에 추가하려는 구성원의 이메일 또는 사용자 이름을 입력합니다.
   3. **Add new member**를 클릭합니다.
