[DeepChem 라이브러리](https://github.com/deepchem/deepchem)는 약물 탐색, 재료 과학, 화학, 생물학 분야에서 딥러닝 활용을 대중화하기 위한 오픈 소스 도구를 제공합니다. 이 W&amp;B 통합은 DeepChem으로 모델을 학습할 때 간편한 실험 추적 및 모델 체크포인트 기능을 제공합니다.

<div id="deepchem-logging-in-3-lines-of-code">
  ## 단 3줄의 코드로 DeepChem 로깅하기
</div>

```python
logger = WandbLogger(…)
model = TorchModel(…, wandb_logger=logger)
model.fit(…)
```

<div id="install-the-wandb-library-and-log-in">
  ### `wandb` 라이브러리를 설치하고 로그인하기
</div>

로컬 환경에서 `wandb` 라이브러리를 설치하고 로그인하려면 다음을 수행하세요:

<Tabs>
  <Tab title="Command Line">
    1. `WANDB_API_KEY` [환경 변수](/ko/models/track/environment-variables/)를 본인의 API key 값으로 설정합니다.

       ```bash
       export WANDB_API_KEY=<your_api_key>
       ```

    2. `wandb` 라이브러리를 설치하고 로그인합니다.

       ```shell
       pip install wandb

       wandb login
       ```

<div id="log-your-training-and-evaluation-data-to-wb">
  ### 학습 및 평가 데이터를 W&amp;B에 기록하기
</div>

학습 손실과 평가 지표는 W&amp;B에 자동으로 기록할 수 있습니다. 선택적인 평가는 DeepChem의 [ValidationCallback](https://github.com/deepchem/deepchem/blob/master/deepchem/models/callbacks.py)을 사용해 활성화할 수 있으며, `WandbLogger`가 ValidationCallback 콜백을 감지해 해당 콜백이 생성한 지표를 기록합니다.

<Tabs>
  <Tab title="TorchModel">
    ```python
    from deepchem.models import TorchModel, ValidationCallback

    vc = ValidationCallback(…)  # 선택 사항
    model = TorchModel(…, wandb_logger=logger)
    model.fit(…, callbacks=[vc])
    logger.finish()
    ```
  </Tab>

  <Tab title="KerasModel">
    ```python
    from deepchem.models import KerasModel, ValidationCallback

    vc = ValidationCallback(…)  # 선택 사항
    model = KerasModel(…, wandb_logger=logger)
    model.fit(…, callbacks=[vc])
    logger.finish()
    ```
  </Tab>
</Tabs>
