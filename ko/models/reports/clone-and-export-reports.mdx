<div id="export-reports">
  ## 리포트 내보내기
</div>

리포트를 PDF 또는 LaTeX 형식으로 내보낼 수 있습니다. 리포트에서 케밥 아이콘을 선택해 드롭다운 메뉴를 연 다음 **Download and**를 선택하고, 출력 형식으로 PDF 또는 LaTeX 중 하나를 선택하세요.

<div id="cloning-reports">
  ## 보고서 복제하기
</div>

<Tabs>
<Tab title="W&B 앱">
보고서에서 케밥 아이콘을 선택해 드롭다운 메뉴를 엽니다. **Clone this report** 버튼을 선택합니다. 모달에서 복제된 보고서를 저장할 위치를 선택합니다. **Clone report**를 선택합니다.

<Frame>
    <img src="/images/reports/clone_reports.gif" alt="보고서 복제하기"  />
</Frame>

프로젝트의 템플릿과 형식을 재사용하려면 보고서를 복제하세요. 팀 계정 내에서 프로젝트를 복제하면 복제된 프로젝트는 팀 전체에 표시됩니다. 개인 계정 내에서 복제된 프로젝트는 해당 사용자에게만 표시됩니다.
</Tab>
<Tab title="Report 및 Workspace API">
템플릿으로 사용하기 위해 URL에서 Report를 로드합니다.

```python
report = wr.Report(
    project=PROJECT, title="Quickstart Report", description="That was easy!"
)  # 생성
report.save()  # 저장
new_report = wr.Report.from_url(report.url)  # 로드
```

`new_report.blocks` 내의 내용을 수정합니다.

```python
pg = wr.PanelGrid(
    runsets=[
        wr.Runset(ENTITY, PROJECT, "First Run Set"),
        wr.Runset(ENTITY, PROJECT, "Elephants Only!", query="elephant"),
    ],
    panels=[
        wr.LinePlot(x="Step", y=["val_acc"], smoothing_factor=0.8),
        wr.BarPlot(metrics=["acc"]),
        wr.MediaBrowser(media_keys="img", num_columns=1),
        wr.RunComparer(diff_only="split", layout={"w": 24, "h": 9}),
    ],
)
new_report.blocks = (
    report.blocks[:1] + [wr.H1("Panel Grid Example"), pg] + report.blocks[1:]
)
new_report.save()
```
