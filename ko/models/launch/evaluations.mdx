이 페이지에는 [LLM Evaluation Jobs](/ko/models/launch)가 제공하는 평가 벤치마크가 범주별로 나열되어 있습니다.

특정 벤치마크를 실행하려면 팀 관리자(team admin)가 필요한 API key를 [team-scoped secrets](/ko/platform/secrets#add-a-secret)로 추가해야 합니다. 모든 팀 구성원은 평가 작업을 구성할 때 해당 secret을 지정할 수 있습니다.

* **OpenAI Model Scorer** 열에 `true`가 표시된 벤치마크는 점수 계산에 OpenAI 모델을 사용합니다. 조직 또는 팀 관리자는 OpenAI API key를 팀 secret으로 추가해야 합니다. 이 요구 사항이 있는 벤치마크로 평가 작업을 구성할 때 **Scorer API key** 필드에 해당 secret을 설정하세요.
  * **Gated Hugging Face Dataset** 열에 링크가 있는 벤치마크는 gated Hugging Face 데이터셋에 대한 액세스가 필요합니다. 조직 또는 팀 관리자는 Hugging Face에서 해당 데이터셋에 대한 액세스를 요청하고, Hugging Face 사용자 액세스 토큰을 생성한 다음, 해당 액세스 키로 팀 secret을 구성해야 합니다. 이 요구 사항이 있는 벤치마크를 구성할 때 **Hugging Face Token** 필드에 해당 secret을 설정하세요.
