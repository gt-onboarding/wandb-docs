`wandb.plot` 메서드를 사용하면 학습 중 시간에 따라 변하는 차트를 포함해 `wandb.Run.log()`을 사용하여 차트를 추적할 수 있습니다. 커스텀 차트 프레임워크에 대해 더 알아보려면 [커스텀 차트 안내](/ko/models/app/features/custom-charts/walkthrough/)를 확인하세요.

<div id="basic-charts">
  ### 기본 차트
</div>

이러한 간단한 차트는 메트릭과 결과의 기본적인 시각화를 손쉽게 만들 수 있게 해 줍니다.

<Tabs>
  <Tab title="선형">
    임의의 축을 기준으로 순서 있는 점들을 연결한 사용자 정의 선형 플롯을 로깅합니다.

    ```python
    import wandb

    with wandb.init() as run:
        data = [[x, y] for (x, y) in zip(x_values, y_values)]
        table = wandb.Table(data=data, columns=["x", "y"])
        run.log(
            {
                "my_custom_plot_id": wandb.plot.line(
                    table, "x", "y", title="Custom Y vs X Line Plot"
                )
            }
        )
    ```

    이 기능을 사용하여 임의의 두 차원에 대한 곡선을 로그로 남길 수 있습니다. 두 개의 값 리스트를 서로에 대해 플로팅하는 경우, 두 리스트의 값 개수는 반드시 정확히 일치해야 합니다. 예를 들어, 각 점에는 x와 y 값이 모두 있어야 합니다.

<Tabs>
  <Tab title="정밀도-재현율 곡선">
    한 줄 코드로 [Precision-Recall 곡선](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.precision_recall_curve.html#sklearn.metrics.precision_recall_curve)을 생성합니다:

    ```python
    import wandb
    with wandb.init() as run:
        # ground_truth는 실제 레이블 목록이고, predictions는 예측 점수 목록입니다
        # 예: ground_truth = [0, 1, 1, 0], predictions = [0.1, 0.4, 0.35, 0.8]
        ground_truth = [0, 1, 1, 0]
        predictions = [0.1, 0.4, 0.35, 0.8]
        run.log({"pr": wandb.plot.pr_curve(ground_truth, predictions)})
    ```

    코드에서 다음 정보에 접근할 수 있을 때마다 이를 로깅할 수 있습니다:

    * 예제 집합에 대한 모델의 예측 점수(`predictions`)
    * 해당 예제에 대한 정답 레이블(`ground_truth`)
    * (선택 사항) 레이블/클래스 이름 목록 (예: 레이블 인덱스 0이 cat, 1이 dog, 2가 bird 등을 의미한다면 `labels=["cat", "dog", "bird"...]`)
    * (선택 사항) 플롯에서 시각화할 레이블의 부분 집합(리스트 형식 유지)

    한 줄짜리 코드로 다중 클래스 [confusion matrix](https://scikit-learn.org/stable/auto_examples/model_selection/plot_confusion_matrix.html)를 생성하세요:

    ```python
    import wandb

    cm = wandb.plot.confusion_matrix(
        y_true=ground_truth, preds=predictions, class_names=class_names
    )

    with wandb.init() as run:
        run.log({"conf_mat": cm})
    ```

    코드에서 다음 정보에 접근할 수 있는 어느 위치에서든 이를 로깅할 수 있습니다:

    * 해당 예시들에 대한 정답(ground truth) 레이블(`y_true`)
    * 문자열로 된 레이블/클래스 이름 전체 리스트인 `class_names`. 예: 인덱스 0이 `cat`, 1이 `dog`, 2가 `bird`인 경우 `class_names=["cat", "dog", "bird"]`.

  ### 상호작용형 커스텀 차트

완전한 수준의 사용자 정의가 필요하다면, 기본 제공되는 [Custom Chart 프리셋](/ko/models/app/features/custom-charts/walkthrough/)을 수정하거나 새 프리셋을 만든 뒤 차트를 저장하세요. 스크립트에서 해당 커스텀 프리셋으로 직접 데이터를 로깅하려면 차트 ID를 사용하세요.

```python
import wandb
# 플롯할 열이 있는 테이블 생성
table = wandb.Table(data=data, columns=["step", "height"])

# 테이블의 열을 차트의 필드에 매핑
fields = {"x": "step", "value": "height"}

# 테이블을 사용하여 새 커스텀 차트 프리셋 채우기
# 저장된 차트 프리셋을 사용하려면 vega_spec_name을 변경
# 제목을 편집하려면 string_fields를 변경
my_custom_chart = wandb.plot_table(
    vega_spec_name="carey/new_chart",
    data_table=table,
    fields=fields,
    string_fields={"title": "Height Histogram"},
)

with wandb.init() as run:
    # 커스텀 차트 로깅
    run.log({"my_custom_chart": my_custom_chart})
```

<div id="matplotlib-and-plotly-plots">
  ### Matplotlib 및 Plotly 플롯
</div>

`wandb.plot()`를 사용해 W&amp;B [Custom Charts](/ko/models/app/features/custom-charts/walkthrough/)를 만드는 대신, [matplotlib](https://matplotlib.org/) 및 [Plotly](https://plotly.com/)로 생성한 차트를 기록할 수 있습니다.

```python
import wandb
import matplotlib.pyplot as plt

with wandb.init() as run:
    # 간단한 matplotlib 플롯 생성
    plt.figure()
    plt.plot([1, 2, 3, 4])
    plt.ylabel("some interesting numbers")
    
    # W&B에 플롯 기록
    run.log({"chart": plt})
```

`matplotlib` 플롯이나 figure 객체를 그대로 `wandb.Run.log()`에 전달하세요. 기본적으로 이 플롯은 [Plotly](https://plot.ly/) 플롯으로 변환됩니다. 플롯을 이미지로 로깅하려면 플롯을 `wandb.Image`에 전달하면 됩니다. Plotly 차트도 직접 로깅할 수 있습니다.

<Note>
  “You attempted to log an empty plot” 오류가 발생한다면, `fig = plt.figure()`로 플롯과는 별도로 figure를 생성해 저장한 뒤, `wandb.Run.log()`를 호출할 때 `fig`를 로깅하면 됩니다.
</Note>

<div id="log-custom-html-to-wb-tables">
  ### 커스텀 HTML을 W&amp;B Tables에 기록하기
</div>

W&amp;B는 Plotly와 Bokeh의 인터랙티브 차트를 HTML로 기록하고 이를 Tables에 추가하는 기능을 지원합니다.

<div id="log-plotly-figures-to-tables-as-html">
  #### Plotly figure를 HTML 형태로 Tables에 로깅하기
</div>

대화형 Plotly 차트를 HTML로 변환해 wandb Tables에 로깅할 수 있습니다.

```python
import wandb
import plotly.express as px

# 새 실행 초기화
with wandb.init(project="log-plotly-fig-tables", name="plotly_html") as run:

    # 테이블 생성
    table = wandb.Table(columns=["plotly_figure"])

    # Plotly 그림 경로 생성
    path_to_plotly_html = "./plotly_figure.html"

    # Plotly 그림 예시
    fig = px.scatter(x=[0, 1, 2, 3, 4], y=[0, 1, 4, 9, 16])

    # Plotly 그림을 HTML로 저장
    # auto_play를 False로 설정하면 애니메이션 Plotly 차트가
    # 테이블에서 자동으로 재생되는 것을 방지
    fig.write_html(path_to_plotly_html, auto_play=False)

    # Plotly 그림을 HTML 파일로 테이블에 추가
    table.add_data(wandb.Html(path_to_plotly_html))

    # 테이블 로깅
    run.log({"test_table": table})
```

<div id="log-bokeh-figures-to-tables-as-html">
  #### Bokeh 그래프를 HTML로 Tables에 로깅하기
</div>

대화형 Bokeh 차트를 HTML로 변환한 뒤 wandb Tables에 로깅할 수 있습니다.

```python
from scipy.signal import spectrogram
import holoviews as hv
import panel as pn
from scipy.io import wavfile
import numpy as np
from bokeh.resources import INLINE

hv.extension("bokeh", logo=False)
import wandb


def save_audio_with_bokeh_plot_to_html(audio_path, html_file_name):
    sr, wav_data = wavfile.read(audio_path)
    duration = len(wav_data) / sr
    f, t, sxx = spectrogram(wav_data, sr)
    spec_gram = hv.Image((t, f, np.log10(sxx)), ["Time (s)", "Frequency (hz)"]).opts(
        width=500, height=150, labelled=[]
    )
    audio = pn.pane.Audio(wav_data, sample_rate=sr, name="Audio", throttle=500)
    slider = pn.widgets.FloatSlider(end=duration, visible=False)
    line = hv.VLine(0).opts(color="white")
    slider.jslink(audio, value="time", bidirectional=True)
    slider.jslink(line, value="glyph.location")
    combined = pn.Row(audio, spec_gram * line, slider).save(html_file_name)


html_file_name = "audio_with_plot.html"
audio_path = "hello.wav"
save_audio_with_bokeh_plot_to_html(audio_path, html_file_name)

wandb_html = wandb.Html(html_file_name)

with wandb.init(project="audio_test") as run:
    my_table = wandb.Table(columns=["audio_with_plot"], data=[[wandb_html]])
    run.log({"audio_table": my_table})
```
