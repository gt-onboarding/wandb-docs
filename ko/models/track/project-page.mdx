*프로젝트*는 결과를 시각화하고, 실험을 비교하고, 아티팩트를 보고 다운로드하며, 자동화를 생성하는 등 다양한 작업을 수행하는 중심 공간입니다.

<Note>
  각 프로젝트에는 누가 액세스할 수 있는지를 결정하는 공개 범위 설정이 있습니다. 프로젝트에 누가 액세스할 수 있는지에 대한 자세한 내용은 [Project visibility](/ko/platform/hosting/iam/access-management/restricted-projects)를 참조하세요.
</Note>

각 프로젝트에는 다음과 같은 탭이 포함됩니다:

* [Overview](/ko/models/track/project-page/#overview-tab): 프로젝트의 스냅샷
* [Workspace](/ko/models/track/project-page/#workspace-tab): 개인용 시각화 샌드박스
* [Runs](#runs-tab): 프로젝트의 모든 실행이 나열된 표
* [Automations](#automations-tab): 프로젝트에서 구성한 자동화
* [Sweeps](/ko/models/sweeps): 자동화된 탐색 및 최적화
* [Reports](/ko/models/track/project-page/#reports-tab): 노트, 실행, 그래프의 저장된 스냅샷
* [Artifacts](#artifacts-tab): 프로젝트의 모든 실행과 각 실행에 연결된 아티팩트를 포함합니다

<div id="overview-tab">
  ## 개요 탭
</div>

W&amp;B는 실행을 초기화할 때 프로젝트 필드에 입력한 이름으로 프로젝트를 생성합니다.

**개요(Overview)** 탭에서 프로젝트 이름을 확인하고 프로젝트를 관리할 수 있습니다.

* 프로젝트의 이름, 설명 또는 팀을 변경하려면 오른쪽 상단의 **Edit**을 클릭합니다.
* 최근에 삭제된 실행을 복구하려면 오른쪽 상단의 **...**을 클릭한 다음 **Undelete recently deleted runs**를 클릭합니다.
* 프로젝트를 삭제하려면 오른쪽 상단의 **...**을 클릭한 다음 **Delete project**를 클릭합니다. 확인 대화 상자의 내용을 읽고 안내에 따릅니다. 프로젝트 삭제는 되돌릴 수 없습니다.

나머지 **개요(Overview)** 페이지는 **Details** 및 **Project Roles** 탭으로 나뉩니다.

<div id="details">
  ### 세부 정보
</div>

Project에 대한 세부 정보에는 다음이 포함됩니다:

* **Project visibility**: Project의 공개 범위입니다. 누가 이 Project에 액세스할 수 있는지를 결정하는 공개 범위 설정입니다. 자세한 내용은 [Project visibility](/ko/platform/hosting/iam/access-management/restricted-projects)를 참조하세요.
* **Last active**: 이 프로젝트에 데이터가 마지막으로 기록된 시점의 타임스탬프입니다.
* **Contributors**: 이 프로젝트에 기여한 사용자 수입니다.
* **Total runs**: 이 프로젝트에 포함된 실행의 총 개수입니다.
* **Total compute**: 이 프로젝트의 모든 실행 시간을 합산한 총량입니다.

**Details** 탭에는 프로젝트의 데이터와 메트릭에 액세스하고 내보내는 방법, 스윕에서 최상의 모델을 다운로드하는 방법 등에 대한 안내도 포함됩니다.

<div id="workspace-tab">
  ## Workspace 탭
</div>

프로젝트의 *workspace*는 실험을 비교할 수 있는 개인용 샌드박스를 제공합니다. 프로젝트를 사용해 서로 다른 아키텍처, 하이퍼파라미터, 데이터셋, 전처리 방식 등으로 동일한 문제를 풀면서, 비교 가능한 모델들을 체계적으로 구성하세요.

**Runs 사이드바**: 프로젝트에 포함된 모든 실행의 목록입니다.

* **점 메뉴(Dot menu)**: 사이드바의 행 위에 마우스를 올리면 왼쪽에 메뉴가 나타납니다. 이 메뉴를 사용해 실행 이름을 변경하거나, 실행을 삭제하거나, 활성 실행을 중지할 수 있습니다.
* **가시성 아이콘(Visibility icon)**: 눈 모양 아이콘을 클릭해 그래프에 표시할 실행을 켜고 끌 수 있습니다.
* **색상(Color)**: 실행 색상을 기본 제공 프리셋 중 하나 또는 사용자 정의 색상으로 변경합니다.
* **검색(Search)**: 이름으로 실행을 검색합니다. 이 검색은 플롯에 표시되는 실행도 함께 필터링합니다.
* **필터(Filter)**: 사이드바 필터를 사용해 표시되는 실행 범위를 좁힙니다.
* **그룹(Group)**: 설정(config) 컬럼을 선택해 실행을 동적으로 그룹화합니다. 예를 들어 아키텍처별로 그룹화할 수 있습니다. 그룹화를 사용하면 플롯에 평균값을 나타내는 선과, 그래프상의 점들의 분산을 보여주는 음영 영역이 함께 표시됩니다.
* **정렬(Sort)**: 실행을 정렬할 기준 값을 선택합니다. 예를 들어 손실이 가장 낮은 실행이나 정확도가 가장 높은 실행을 기준으로 정렬할 수 있습니다. 정렬은 그래프에 어떤 실행이 표시되는지에 영향을 줍니다.
* **확장 버튼(Expand button)**: 사이드바를 전체 테이블로 확장합니다.
* **실행 개수(Run count)**: 상단 괄호 안 숫자는 프로젝트의 전체 실행 수를 나타냅니다. `(N visualized)`는 눈 모양 아이콘이 켜져 있어 각 플롯에서 시각화할 수 있는 실행 수입니다. 아래 예시에서 그래프는 183개 실행 중 처음 10개만 표시합니다. 그래프를 편집해 표시 가능한 최대 실행 수를 늘릴 수 있습니다.

[Runs 탭](#runs-tab)에서 컬럼을 고정(pinning)하거나 숨기거나 순서를 변경하면, Runs 사이드바에도 이 사용자 지정 내용이 반영됩니다.

**패널 레이아웃(Panels layout)**: 이 임시 작업 공간을 사용해 결과를 탐색하고, 차트를 추가·제거하며, 다양한 지표를 기준으로 모델 버전을 비교하세요.

<div id="add-a-section-of-panels">
  ### 패널 섹션 추가하기
</div>

섹션 드롭다운 메뉴를 클릭하고 &quot;Add section&quot;을 선택해 패널용 새 섹션을 만드세요. 섹션 이름을 바꾸고, 드래그해서 순서를 재정렬하고, 섹션을 펼치거나 접을 수 있습니다.

각 섹션의 오른쪽 상단에는 다음 옵션이 있습니다.

* **Add section**: 드롭다운 메뉴에서 위나 아래에 새 섹션을 추가하거나, 페이지 하단의 버튼을 클릭해 새 섹션을 추가합니다.
* **Rename section**: 섹션의 제목을 변경합니다.
* **Export section to report**: 이 섹션의 패널들을 새 리포트로 저장합니다.
* **Delete section**: 섹션 전체와 모든 차트를 삭제합니다. 이 작업은 워크스페이스 바의 페이지 하단에 있는 실행 취소 버튼으로 되돌릴 수 있습니다.
* **Add panel**: 플러스 버튼을 클릭해 섹션에 패널을 추가합니다.

<Tabs>
  <Tab title="열 사용자 지정">
    **Runs** 탭에는 해당 프로젝트의 실행에 대한 상세 정보가 표시됩니다. 기본적으로 많은 수의 열이 표시됩니다.

    <Note>
      **Runs** 탭에서 열 구성을 변경하면, 이 설정은 [Workspace 탭](#workspace-tab)의 **Runs** 선택기에도 동일하게 반영됩니다.
    </Note>

    * 표시 중인 모든 열을 보려면 페이지를 가로로 스크롤하세요.
    * 열의 순서를 변경하려면 열을 좌우로 드래그하세요.
    * 열을 고정하려면 열 이름 위에 마우스를 올린 뒤 나타나는 `...` 동작 메뉴를 클릭하고 **Pin column**을 선택하세요. 고정된 열은 **Name** 열 다음, 페이지 왼쪽 영역에 표시됩니다. 고정된 열을 해제하려면 **Unpin column**을 선택하세요.
    * 열을 숨기려면 열 이름 위에 마우스를 올린 뒤 나타나는 `...` 동작 메뉴를 클릭하고 **Hide column**을 선택하세요. 현재 숨겨진 모든 열을 보려면 **Columns**를 클릭하세요.
    * 여러 열을 한 번에 표시/숨기기 또는 고정/고정 해제하려면 **Columns**를 클릭하세요.
      * 숨겨진 열의 이름을 클릭하면 다시 표시됩니다.
      * 표시 중인 열의 이름을 클릭하면 숨겨집니다.
      * 표시 중인 열 옆의 핀 아이콘을 클릭하면 해당 열이 고정됩니다.
  </Tab>

  <Tab title="정렬">
    다음 방법 중 하나를 사용하여 특정 열의 값을 기준으로 테이블의 모든 행을 정렬할 수 있습니다.

    1. 아무 열 헤더 위에 마우스를 올렸을 때 나타나는 케밥 메뉴(세로 점 3개 아이콘)를 클릭해, 해당 열의 값 기준으로 테이블을 빠르게 정렬합니다.
    2. **Sort** 버튼을 클릭하고 드롭다운에서 원하는 열을 선택합니다. 이 패널을 사용하면 우선순위를 지정해 여러 열 기준으로 정렬할 수 있습니다.

  <Tab title="필터">
    대시보드 왼쪽 상단의 **Filter** 버튼을 사용해 식(expression)을 기준으로 모든 행을 필터링할 수 있습니다.

    **New filter**를 클릭해 실행 행에 하나 이상의 필터를 추가하세요.
    필터를 설정할 수 있는 세 개의 드롭다운 메뉴가 나타납니다.
    왼쪽부터 순서대로 열 이름, 연산자, 필터 값입니다.

메타데이터 패널에서는 아티팩트의 메타데이터를 확인할 수 있습니다. 이 메타데이터에는 아티팩트를 재구성하는 데 필요한 구성 인자, 추가 정보를 확인할 수 있는 URL, 아티팩트를 로깅한 실행 중에 생성된 메트릭 등이 포함될 수 있습니다. 아티팩트를 생성한 실행의 구성과 히스토리 메트릭도 여기에서 확인할 수 있습니다.

아티팩트의 메타데이터를 보려면:

1. 프로젝트 사이드바에서 **Artifacts** 탭을 선택합니다.
2. 목록에서 아티팩트를 선택하여 해당 아티팩트의 최신 버전에 대한 세부 정보 페이지를 엽니다.
3. **Metadata** 탭을 선택하여 해당 아티팩트와 연결된 메타데이터를 확인합니다.

<div id="usage-panel">
  ### 사용 패널
</div>

<Frame>
  <img src="/images/app_ui/usage_panel.png" alt="Artifact usage panel" />
</Frame>

사용 패널은 웹 앱 외부, 예를 들어 로컬 머신에서 아티팩트를 사용할 수 있도록 아티팩트를 다운로드하는 코드 스니펫을 제공합니다. 이 섹션에는 아티팩트를 출력한 실행과 아티팩트를 입력으로 사용하는 실행이 표시되며, 해당 실행으로 이동할 수 있는 링크도 제공합니다.

아티팩트 사용 정보를 보려면 다음을 수행합니다:

1. 프로젝트 사이드바에서 **Artifacts** 탭을 선택합니다.
2. 목록에서 아티팩트를 선택하여 해당 아티팩트 최신 버전의 세부 정보 페이지를 엽니다.
3. **Usage** 탭을 선택하여 코드 스니펫과 관련 실행을 확인합니다.

<div id="files-panel">
  ### Files 패널
</div>

<Frame>
  <img src="/images/app_ui/files_panel.png" alt="Artifact files panel" />
</Frame>

Files 패널에는 해당 아티팩트와 관련된 파일과 폴더가 표시됩니다. W&amp;B는 실행에 대한 일부 파일을 자동으로 업로드합니다. 예를 들어, `requirements.txt`는 실행에서 사용한 각 라이브러리의 버전을 보여주고, `wandb-metadata.json` 및 `wandb-summary.json`에는 실행에 대한 정보가 포함됩니다. 실행 설정에 따라 아티팩트나 미디어와 같은 다른 파일들도 업로드될 수 있습니다.

아티팩트에 로그된 파일을 보려면:

1. 프로젝트 사이드바에서 **Artifacts** 탭을 선택합니다.
2. 목록에서 아티팩트를 선택해 해당 아티팩트 최신 버전의 상세 페이지를 엽니다.
3. **Files** 탭을 선택해 해당 아티팩트와 관련된 모든 파일을 확인합니다.

<div id="lineage-panel">
  ### Lineage 패널
</div>

<Frame>
  <img src="/images/app_ui/lineage_panel.png" alt="Artifact lineage" />
</Frame>

Lineage 패널은 프로젝트와 연관된 모든 아티팩트와, 이들을 서로 연결하는 실행을 한눈에 보여 줍니다. 실행 유형은 블록으로, 아티팩트는 원형으로 표시되며, 특정 유형의 실행이 특정 유형의 아티팩트를 소비하거나 생성할 때 이를 화살표로 나타냅니다. 왼쪽 열에서 선택한 특정 아티팩트의 유형은 강조되어 표시됩니다.

Explode 토글을 클릭하면 모든 개별 아티팩트 버전과, 해당 버전들을 연결하는 구체적인 실행을 확인할 수 있습니다.

<div id="versions-tab">
  ### Versions 탭
</div>

<Frame>
  <img src="/images/app_ui/versions_tab.png" alt="Artifact versions tab" />
</Frame>

Versions 탭은 아티팩트의 모든 버전을 표시합니다. 특정 버전의 세부 정보를 보려면 아티팩트를 선택합니다.

1. 프로젝트 사이드바에서 **Artifacts** 탭을 선택합니다.
2. 목록에서 아티팩트를 선택하여 해당 아티팩트의 최신 버전 세부 정보 페이지를 엽니다.

4. 드롭다운(아티팩트 이름 옆)을 열고 **All Versions**를 선택합니다.

예를 들어, 앞의 이미지는 `"zoo-wyhak4p0"`라는 이름의 모델 아티팩트의 서로 다른 버전들을 보여줍니다.

<div id="create-a-project">
  ## 프로젝트 생성
</div>

W&amp;B 앱에서 Project를 생성하거나, `wandb.init()` 호출에서 `project`를 지정해 코드로 프로젝트를 생성할 수 있습니다.

<Tabs>
  <Tab title="W&B 앱">
    W&amp;B 앱에서는 **Projects** 페이지나 팀 랜딩 페이지에서 프로젝트를 생성할 수 있습니다.

    **Projects** 페이지에서:

    1. 왼쪽 상단의 글로벌 내비게이션 아이콘을 클릭합니다. 내비게이션 사이드바가 열립니다.
    2. 내비게이션의 **Projects** 섹션에서 **View all**을 클릭해 프로젝트 개요 페이지를 엽니다.
    3. **Create new project**를 클릭합니다.
    4. **Team**을 이 프로젝트를 소유할 팀 이름으로 설정합니다.
    5. **Name** 필드에 프로젝트 이름을 입력합니다.
    6. 기본값이 **Team**인 **Project visibility**를 설정합니다.
    7. 필요하다면 **Description**을 입력합니다.
    8. **Create project**를 클릭합니다.

    팀 랜딩 페이지에서:

    1. 왼쪽 상단의 글로벌 내비게이션 아이콘을 클릭합니다. 내비게이션 사이드바가 열립니다.
    2. 내비게이션의 **Teams** 섹션에서 팀 이름을 클릭해 해당 팀의 랜딩 페이지를 엽니다.
    3. 랜딩 페이지에서 **Create new project**를 클릭합니다.
    4. **Team**은 방금 보고 있던 랜딩 페이지를 소유한 팀으로 자동 설정됩니다. 필요하면 팀을 변경합니다.
    5. **Name** 필드에 프로젝트 이름을 입력합니다.
    6. 기본값이 **Team**인 **Project visibility**를 설정합니다.
    7. 필요하다면 **Description**을 입력합니다.
    8. **Create project**를 클릭합니다.
  </Tab>

  <Tab title="Python SDK">
    프로그래밍 방식으로 프로젝트를 생성하려면 `wandb.init()` 호출 시 `project`를 지정합니다. 프로젝트가 아직 존재하지 않으면 지정한 엔터티 소유의 프로젝트가 자동으로 생성됩니다. 예:

    ```python
    import wandb

    with wandb.init(entity="<entity>", project="<project_name>") as run:
        run.log({"accuracy": .95})
    ```

    [`wandb.init()` API 레퍼런스](/ko/models/ref/python/functions/init/#examples)를 참조하세요.
  </Tab>
</Tabs>

<div id="star-a-project">
  ## 프로젝트에 별표 표시
</div>

프로젝트에 별표를 추가하여 해당 프로젝트를 중요하게 표시할 수 있습니다. 사용자와 팀에서 별표로 중요하게 표시한 프로젝트는 조직 홈페이지 상단에 표시됩니다.

예를 들어, 다음 이미지는 중요하게 표시된 두 개의 프로젝트인 `zoo_experiment`와 `registry_demo`를 보여줍니다. 두 프로젝트 모두 조직 홈페이지 상단의 **Starred projects** 섹션에 나타납니다.

<Frame>
  <img src="/images/track/star-projects.png" alt="Starred projects 섹션" />
</Frame>

프로젝트를 중요하게 표시하는 방법은 두 가지입니다. 프로젝트의 개요 탭에서 설정하거나 팀 프로필 페이지에서 설정할 수 있습니다.

<Tabs>
  <Tab title="Project overview">
    1. W&amp;B App에서 `https://wandb.ai/<team>/<project-name>` 경로로 이동하여 해당 W&amp;B 프로젝트를 엽니다.
    2. 프로젝트 사이드바에서 **Overview** 탭을 선택합니다.
    3. 오른쪽 상단의 **Edit** 버튼 옆에 있는 별 아이콘을 선택합니다.

    <Frame>
      <img src="/images/track/star-project-overview-tab.png" alt="Overview에서 프로젝트에 별표 추가" />
    </Frame>
  </Tab>

  <Tab title="Team profile">
    1. `https://wandb.ai/<team>/projects` 에서 팀의 프로필 페이지로 이동합니다.
    2. **Projects** 탭을 선택합니다.
    3. 별표를 추가하려는 프로젝트 옆에 마우스를 올립니다. 나타나는 별 아이콘을 클릭합니다.

    예를 들어, 다음 이미지는 &quot;Compare&#95;Zoo&#95;Models&quot; 프로젝트 옆에 있는 별 아이콘을 보여줍니다.

    <Frame>
      <img src="/images/track/star-project-team-profile-page.png" alt="팀 페이지에서 프로젝트에 별표 추가" />
    </Frame>
  </Tab>
</Tabs>

앱 왼쪽 상단에서 조직 이름을 클릭하여, 조직 홈페이지에 해당 프로젝트가 표시되는지 확인합니다.

<div id="delete-a-project">
  ## 프로젝트 삭제
</div>

오버뷰 탭 오른쪽에 있는 점 세 개 아이콘을 클릭해서 프로젝트를 삭제할 수 있습니다.

1. W&amp;B 프로젝트로 이동합니다.
2. 프로젝트 사이드바에서 **Overview** 탭을 선택합니다.
3. 오른쪽 상단의 점 세 개 메뉴 아이콘을 선택합니다.
4. 드롭다운 메뉴에서 **Delete project**를 선택합니다.

<Frame>
  <img src="/images/app_ui/delete_project.png" alt="드롭다운에 프로젝트 삭제 옵션이 있는 Project 오버뷰 메뉴" />
</Frame>

<Warning>
  프로젝트를 삭제해도 W&amp;B는 활성 상태인 [sweeps](/ko/models/sweeps)나 에이전트를 종료하지 않습니다.
</Warning>

<div id="add-notes-to-a-project">
  ## 프로젝트에 노트 추가하기
</div>

워크스페이스에서 프로젝트에 노트를 추가할 때, 개요 설명으로 추가하거나 마크다운 패널로 추가할 수 있습니다.

<div id="add-description-overview-to-a-project">
  ### Project에 개요 설명 추가
</div>

페이지에 추가한 설명은 프로필의 **Overview** 탭에 표시됩니다.

1. W&amp;B 프로젝트로 이동합니다.
2. 프로젝트 사이드바에서 **Overview** 탭을 선택합니다.
3. 오른쪽 상단의 Edit를 클릭합니다.
4. **Description** 필드에 메모를 입력합니다.
5. **Save** 버튼을 클릭합니다.

<Note>
  **실행 비교용 설명 메모는 Report로 작성하세요**

  W&amp;B Report를 만들어 플롯과 마크다운을 나란히 배치할 수도 있습니다. 서로 다른 섹션을 사용해 다른 실행을 보여 주면서, 작업한 내용에 대한 스토리를 구성하세요.
</Note>

<div id="add-notes-to-run-workspace">
  ### 실행 워크스페이스에 메모 추가
</div>

1. 사용 중인 W&amp;B 프로젝트로 이동합니다
2. 프로젝트 사이드바에서 **Workspace** 탭을 선택합니다
3. 오른쪽 상단에서 **Add panels** 버튼을 클릭합니다
4. 표시되는 모달에서 **TEXT AND CODE** 드롭다운 메뉴를 선택합니다
5. **Markdown**을 선택합니다
6. 워크스페이스에 추가된 마크다운 패널에 메모를 작성합니다
