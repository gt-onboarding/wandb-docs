W&amp;B Tables를 사용해 표 형식 데이터를 시각화하고 쿼리할 수 있습니다. 예를 들면 다음과 같습니다:

* 동일한 테스트 세트에서 서로 다른 모델의 성능을 비교합니다
* 데이터에서 패턴을 식별합니다
* 샘플 모델 예측 결과를 시각적으로 확인합니다
* 자주 오분류되는 예시를 찾기 위해 쿼리합니다

<div id="how-it-works">
  ## 작동 방식
</div>

Table은 각 열이 하나의 데이터 타입만 가지는 2차원 데이터 그리드입니다. Table은 기본형 및 수치형 타입뿐만 아니라 중첩 리스트, 딕셔너리, 리치 미디어 타입도 지원합니다.

<div id="log-a-table">
  ## Table 기록하기
</div>

몇 줄의 코드만으로 Table을 기록할 수 있습니다:

* [`wandb.init()`](/ko/models/ref/python/functions/init): 결과를 추적할 [실행](/ko/models/runs/)을 생성합니다.
* [`wandb.Table()`](/ko/models/ref/python/data-types/table): 새 Table 객체를 생성합니다.
  * `columns`: 열 이름을 설정합니다.
  * `data`: Table의 내용을 설정합니다.
* [`run.log()`](/ko/models/ref/python/experiments/run.md/#method-runlog): Table을 로그로 남겨 W&amp;B에 저장합니다.

```python
import wandb

with wandb.init(project="table-test") as run:
    my_table = wandb.Table(columns=["a", "b"], data=[["a1", "b1"], ["a2", "b2"]])
    run.log({"Table Name": my_table})
```
