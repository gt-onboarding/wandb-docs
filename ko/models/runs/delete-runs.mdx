title: 실행 삭제
description: W&B App을 사용하여 W&B 프로젝트에서 실행을 삭제하는 방법을 알아보세요.
---

W&B App을 사용하여 프로젝트에서 하나 이상의 실행을 삭제할 수 있습니다.

1. 삭제하려는 실행을 포함하는 프로젝트로 이동합니다.
2. **Runs** 탭을 선택합니다.
3. 삭제하려는 실행 옆의 체크박스를 선택합니다.
4. 테이블 위에 있는 **Delete** 버튼(휴지통 아이콘)을 선택합니다.
5. 표시되는 드로어에서 **Delete**를 선택합니다.

<Note>
실행 ID는 실행이 삭제된 후에도 다시 사용할 수 없습니다. 이렇게 하면 해당 실행은 오류가 발생하며 실패합니다.
</Note>

<Note>
많은 수의 실행을 포함하는 프로젝트의 경우, 검색창에서 정규식(Regex)을 사용해 삭제하려는 실행을 필터링하거나, 필터 버튼을 사용해 상태, 태그 또는 기타 속성에 따라 실행을 필터링할 수 있습니다.
</Note>

  ### 실행 삭제 흐름도

다음 다이어그램은 관련 아티팩트와 Registry 링크 처리를 포함한 전체 실행 삭제 과정을 보여줍니다.

```mermaid
graph TB
    Start([사용자가 실행<br/>삭제 시작]) --> RunSelect[삭제할 실행<br/>선택]
    
    RunSelect --> DeletePrompt{연결된 아티팩트<br/>삭제?}
    
    DeletePrompt -->|아니오| DeleteRunOnly[실행만 삭제<br/><br/>- 실행 메타데이터 제거됨<br/>- 아티팩트는 계속 사용 가능<br/>- 아티팩트 접근 가능]
    
    DeletePrompt -->|예| CheckArtifacts[연결된 아티팩트<br/>확인]
    
    CheckArtifacts --> HasRegistry{Model Registry에<br/>연결된 아티팩트?}
    
    HasRegistry -->|예| RegistryWarning[⚠️ 경고<br/><br/>Registry 모델이 삭제됩니다<br/>프로덕션 별칭에 영향을 미침]
    HasRegistry -->|아니오| DirectDelete
    
    RegistryWarning --> ConfirmRegistry{Registry<br/>모델 삭제 확인?}
    
    ConfirmRegistry -->|아니오| DeleteRunOnly
    ConfirmRegistry -->|예| DirectDelete[실행 + 아티팩트 삭제<br/><br/>- 실행 메타데이터 제거됨<br/>- 아티팩트 영구 삭제됨<br/>- Registry 링크 제거됨<br/>- 복구 불가]
    
    DeleteRunOnly --> PartialEnd([실행 삭제됨<br/>아티팩트 보존됨])
    DirectDelete --> FullEnd([실행 + 아티팩트<br/>영구 삭제됨])

    style RegistryWarning fill:#ffecb3,stroke:#333,stroke-width:2px,color:#000

    style DeleteRunOnly fill:#e8f5e9,stroke:#333,stroke-width:2px,color:#000
    style PartialEnd fill:#c8e6c9,stroke:#333,stroke-width:2px,color:#000
    style FullEnd fill:#ffcdd2,stroke:#333,stroke-width:2px,color:#000
```

<Warning>
  실행을 삭제할 때 관련 아티팩트를 함께 삭제하도록 선택하면, 해당 아티팩트는 영구적으로 삭제되며 실행을 나중에 복원하더라도 복구할 수 없습니다. 여기에는 Registry에 연결된 아티팩트도 포함됩니다.
</Warning>
