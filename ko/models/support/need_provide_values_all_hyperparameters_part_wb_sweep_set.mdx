---
title: W&amp;B Sweep에서 모든 하이퍼파라미터 값을 다 지정해야 하나요?
  기본값을 설정할 수 있나요?
---

`(run.config())`을 사용하여 Sweep 설정에서 하이퍼파라미터 이름과 값을 가져올 수 있으며, 이는 딕셔너리처럼 동작합니다.

Sweep 외부에서 실행되는 실행에서는 `wandb.init()`의 `config` 인수에 딕셔너리를 전달하여 `wandb.Run.config()` 값을 설정합니다. Sweep 내에서는 `wandb.init()`에 전달한 모든 설정이 기본값으로 사용되며, Sweep이 이를 덮어쓸 수 있습니다.

명시적인 동작을 원한다면 `wandb.Run.config.setdefaults()`를 사용하세요. 다음 코드 스니펫은 두 가지 방법을 모두 보여줍니다:

<Tabs>
<Tab title="wandb.init()">
```python
# 하이퍼파라미터에 대한 기본값 설정
config_defaults = {"lr": 0.1, "batch_size": 256}

# 실행을 시작하면서
# Sweep이 덮어쓸 수 있는 기본값을 제공
with wandb.init(config=config_defaults) as run:
    # 여기에 학습 코드를 추가하세요.
    ...
```
</Tab>
<Tab title="config.setdefaults()">
```python
# 하이퍼파라미터에 대한 기본값 설정
config_defaults = {"lr": 0.1, "batch_size": 256}

# 실행 시작
with wandb.init() as run:
    # Sweep에서 설정하지 않은 값만 기본값으로 갱신
    run.config.setdefaults(config_defaults)

    # 여기에 학습 코드를 추가하세요.
```
</Tab>
</Tabs>
