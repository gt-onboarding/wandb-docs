---
title: 지속적 통합 또는 내부 도구에서 시작된 실행은 어떻게 로깅하나요?
---

자동화된 테스트나 W&B에 로그를 남기는 내부 도구 실행을 시작하려면 팀 설정 페이지에서 **Service Account**를 생성하세요. 이렇게 하면 지속적 통합을 통해 실행되는 작업을 포함해 자동화된 작업에서 사용할 서비스용 API key를 쓸 수 있습니다. 서비스 계정으로 실행되는 작업을 특정 사용자에게 귀속하려면 `WANDB_USERNAME` 또는 `WANDB_USER_EMAIL` 환경 변수를 설정하세요.
