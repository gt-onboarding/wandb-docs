---
title: 계정이 없는 사람은 실행 결과를 어떻게 볼 수 있나요?
---

누군가 `anonymous="allow"`로 스크립트를 실행하면:

1. **임시 계정 자동 생성**: W&B는 로그인된 계정이 있는지 확인합니다. 계정이 없으면 W&B가 새로운 익명 계정을 만들고 해당 세션용 API key를 저장합니다.
2. **빠르게 결과 로깅**: 사용자는 스크립트를 여러 번 실행하고 W&B 대시보드에서 결과를 즉시 확인할 수 있습니다. 이 소유자가 없는 익명 실행은 7일 동안 유지됩니다.
3. **유용할 때 데이터 가져오기**: 사용자가 W&B에서 가치 있는 결과를 찾으면, 페이지 상단 배너의 버튼을 클릭해 실행 데이터를 실제 계정으로 옮길 수 있습니다. 가져오기를 하지 않으면 실행 데이터는 7일 후 삭제됩니다.

<Warning>
**익명 실행 링크는 민감한 정보입니다**. 이 링크가 있으면 누구나 7일 동안 실험 결과를 조회하고 소유권을 가져올 수 있으므로, 신뢰할 수 있는 사람에게만 공유해야 합니다. 작성자의 신원을 숨긴 상태로 결과를 공개적으로 공유하려면 support@wandb.com으로 문의해 도움을 받으세요.
</Warning>

W&B 사용자가 스크립트를 찾아 실행하면, 일반적인 실행과 마찬가지로 해당 사용자의 계정에 결과가 올바르게 로깅됩니다.
