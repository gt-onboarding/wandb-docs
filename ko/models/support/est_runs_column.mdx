---
title: "`Est. Runs` 열은 무엇인가요?"
---

W&amp;B는 이산 검색 공간(discrete search space)을 사용하는 W&amp;B Sweep을 생성할 때 생성될 실행 수를 추정해서 제공합니다. 이 값은 검색 공간의 데카르트 곱(Cartesian product)을 반영한 결과입니다.

예를 들어, 다음과 같은 검색 공간을 고려해 보겠습니다:

<Frame>
  <img src="/images/sweeps/sweeps_faq_whatisestruns_1.png" alt="예상 실행 수 열" />
</Frame>

이 경우 데카르트 곱은 9가 됩니다. W&amp;B는 이 값을 앱 UI에서 추정 실행 수(**Est. Runs**)로 표시합니다:

<Frame>
  <img src="/images/sweeps/spaces_sweeps_faq_whatisestruns_2.webp" alt="Sweep 실행 수 추정" />
</Frame>

추정 실행 수를 프로그래밍 방식으로 가져오려면, W&amp;B SDK의 Sweep 객체에서 `expected_run_count` 속성을 사용하세요:

```python
sweep_id = wandb.sweep(
    sweep_configs, project="your_project_name", entity="your_entity_name"
)
api = wandb.Api()
sweep = api.sweep(f"your_entity_name/your_project_name/sweeps/{sweep_id}")
print(f"EXPECTED RUN COUNT = {sweep.expected_run_count}")
```
