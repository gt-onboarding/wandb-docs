---
title: W&B Inference에서 Invalid Authentication (401) 오류를 해결하는 방법
---

401 Invalid Authentication 오류는 API key가 유효하지 않거나 W&B 프로젝트 엔터티/이름이 올바르지 않음을 의미합니다.

<div id="verify-your-api-key">
  ## API key 확인
</div>

1. [User Settings](https://wandb.ai/settings)에서 새 API key를 생성합니다.
2. API key를 안전하게 보관합니다.

<div id="check-your-project-configuration">
  ## 프로젝트 구성을 확인하세요
</div>

프로젝트가 `<your-team>/<your-project>` 형식으로 올바르게 설정되어 있는지 확인하세요:

**Python 예시:**

```python
client = openai.OpenAI(
    base_url='https://api.inference.wandb.ai/v1',
    api_key="<your-api-key>",
    project="<your-team>/<your-project>",  # W&B 팀 및 프로젝트와 일치해야 합니다
)
```

**Bash 예제:**

```bash
curl https://api.inference.wandb.ai/v1/chat/completions \
  -H "Authorization: Bearer <your-api-key>" \
  -H "OpenAI-Project: <your-team>/<your-project>"
```


<div id="common-mistakes">
  ## 일반적인 실수
</div>

- 팀 이름 대신 개인 엔터티를 사용하는 경우
- 팀 또는 프로젝트 이름을 오타로 잘못 입력한 경우
- 팀과 프로젝트 이름 사이에 슬래시(`/`)를 넣지 않은 경우
- 만료되었거나 삭제된 API key를 사용하는 경우

<div id="still-having-issues">
  ## 아직 문제가 있나요?
</div>

- W&B 계정에 해당 팀과 프로젝트가 존재하는지 확인하세요
- 지정한 팀에 대한 접근 권한이 있는지 확인하세요
- 현재 API key가 동작하지 않으면 새 API key를 만들어 보세요
