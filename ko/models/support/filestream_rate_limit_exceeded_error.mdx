---
title: Filestream rate limit exceeded 오류를 어떻게 해결할 수 있나요?
---

W&B에서 "Filestream rate limit exceeded" 오류를 해결하려면 다음 단계를 따르세요:

**로깅 최적화**:

- API 요청 수를 줄이기 위해 로깅 빈도를 낮추거나 로그를 배치로 전송하세요.
  - 실험 시작 시간을 분산시켜 동시에 API 요청이 발생하지 않도록 하세요.

**장애 여부 확인**:

- [W&B 상태 업데이트](https://status.wandb.com)를 확인해 일시적인 서버 측 문제로 인해 발생한 것이 아닌지 확인하세요.

**지원 팀에 문의**:

- 요청 한도 상향을 요청하기 위해 실험 설정에 대한 상세 정보와 함께 W&B 지원팀(support@wandb.com)에 문의하세요.
