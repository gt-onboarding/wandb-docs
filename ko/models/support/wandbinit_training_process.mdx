---
title: wandb.init은 내 학습 프로세스에 어떤 일을 하나요?
---

`wandb.init()`이 학습 스크립트에서 실행되면, API 호출을 통해 서버에 실행 객체가 생성됩니다. 새 프로세스가 시작되어 지표를 스트리밍하고 수집하며, 메인 프로세스는 정상적으로 동작할 수 있습니다. 스크립트는 로컬 파일에 기록하고, 별도의 프로세스는 시스템 지표를 포함한 데이터를 서버로 스트리밍합니다. 스트리밍을 끄려면 학습 디렉터리에서 `wandb off`를 실행하거나 `WANDB_MODE` 환경 변수를 `offline`으로 설정하세요.
