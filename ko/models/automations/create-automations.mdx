<div id="requirements">
  ## 요구 사항
</div>

* 팀 관리자는 팀의 프로젝트에 대한 자동화와 웹후크, 시크릿, Slack 통합과 같은 자동화 구성 요소를 생성하고 관리할 수 있습니다. [Team settings](/ko/platform/app/settings-page/teams/)를 참조하십시오.
* 레지스트리 자동화를 생성하려면 레지스트리에 대한 접근 권한이 있어야 합니다. [Configure Registry access](/ko/models/registry/configure_registry/#registry-roles)를 참조하십시오.
* Slack 자동화를 생성하려면 선택한 Slack 인스턴스와 채널에 메시지를 게시할 수 있는 권한이 필요합니다.

<div id="create-an-automation">
  ## 자동화 생성
</div>

Project 또는 Registry의 **Automations** 탭에서 자동화를 생성할 수 있습니다. 자동화를 생성하는 전체 흐름은 다음과 같습니다:

1. 필요하다면, 자동화에 필요한 각 민감한 문자열(액세스 토큰, 비밀번호, SSH 키 등)에 대해 [W&amp;B Secret 생성](/ko/platform/secrets/)을 수행합니다. Secret은 **Team Settings**에서 정의합니다. Secret은 주로 웹훅 자동화에서 사용됩니다.
2. 팀 수준의 webhook 또는 Slack 연동을 구성하여, W&amp;B가 Slack에 메시지를 게시하거나 웹훅을 대신 실행할 수 있도록 권한을 부여합니다. 하나의 webhook 또는 Slack 연동은 여러 자동화에서 재사용할 수 있습니다. 이러한 작업은 **Team Settings**에서 정의합니다.
3. Project 또는 Registry에서 감시할 이벤트와 수행할 작업(예: Slack에 게시하거나 웹훅 실행)을 지정하는 자동화를 생성합니다. 웹훅 자동화를 생성할 때는 전송할 페이로드(payload)를 구성합니다.

또는 Workspace의 선형 플롯(line plot)에서, 해당 플롯이 표시하는 지표에 대해 빠르게 [실행 지표 자동화](/ko/models/automations/automation-events/#run-events)를 생성할 수 있습니다:

1. 패널 위에 마우스를 올린 다음, 패널 상단의 종(bell) 아이콘을 클릭합니다.

   <Frame>
     <img src="/images/automations/run_metric_automation_from_panel.png" alt="자동화 종 아이콘 위치" />
   </Frame>
2. 기본 또는 고급 구성 컨트롤을 사용해 자동화를 설정합니다. 예를 들어, 실행 필터를 적용해 자동화의 범위를 제한하거나, 절대 임계값을 구성할 수 있습니다.

자세한 내용은 다음을 참조하십시오:

* [Slack 자동화 생성](/ko/models/automations/create-automations/slack/)
* [Webhook 자동화 생성](/ko/models/automations/create-automations/webhook/)

<div id="view-and-manage-automations">
  ## 자동화 보기 및 관리
</div>

프로젝트 또는 레지스트리의 **Automations** 탭에서 자동화를 조회하고 관리할 수 있습니다.

* 자동화의 세부 정보를 보려면 이름을 클릭합니다.
* 자동화의 실행 이력을 보려면 이름을 클릭한 후 **History** 탭을 선택합니다. 자세한 내용은 [자동화 이력 보기](/ko/models/automations/view-automation-history)를 참조하세요.
* 자동화를 편집하려면 해당 자동화의 `...` 작업 메뉴를 클릭한 후 **Edit automation**을 클릭합니다.
* 자동화를 삭제하려면 해당 자동화의 `...` 작업 메뉴를 클릭한 후 **Delete automation**을 클릭합니다.
