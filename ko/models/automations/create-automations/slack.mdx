이 페이지에서는 Slack [자동화](/ko/models/automations/)를 생성하는 방법을 설명합니다. 웹후크 자동화를 생성하려면 대신 [웹후크 자동화 생성](/ko/models/automations/create-automations/webhook/)을 참고하십시오.

Slack 자동화를 생성하는 전체적인 단계는 다음과 같습니다:

1. W&amp;B가 Slack 워크스페이스와 채널에 메시지를 게시할 수 있도록 권한을 부여하는 [Slack 통합 추가](#add-a-slack-integration) 단계를 수행합니다.
2. 감시할 [이벤트](/ko/models/automations/automation-events/)와 알림을 보낼 채널을 정의하는 [자동화 생성](#create-an-automation) 단계를 수행합니다.

<div id="add-a-slack-integration">
  ## Slack 통합 추가
</div>

팀 관리자는 팀에 Slack 통합을 추가할 수 있습니다.

1. W&amp;B에 로그인한 후 **Team Settings**로 이동합니다.
2. **Slack channel integrations** 섹션에서 **Connect Slack**을 클릭해 새로운 Slack 인스턴스를 추가합니다. 기존 Slack 인스턴스에 채널을 추가하려면 **New integration**을 클릭합니다.

   ![Screenshot showing two Slack integrations in a Team](/images/automations/slack_integrations.png)
3. 필요하다면 브라우저에서 Slack에 로그인합니다. 안내가 표시되면, 선택한 Slack 채널에 W&amp;B가 게시할 수 있도록 권한을 허용합니다. 페이지 내용을 확인한 뒤 **Search for a channel**을 클릭하고 채널 이름 입력을 시작합니다. 목록에서 채널을 선택한 다음 **Allow**를 클릭합니다.
4. Slack에서 방금 선택한 채널로 이동합니다. `[Your Slack handle] added an integration to this channel: Weights & Biases`와 같은 메시지가 보이면 통합이 올바르게 구성된 것입니다.

이제 구성한 Slack 채널에 알림을 보내는 [자동화를 생성](#create-an-automation)할 수 있습니다.

<div id="view-and-manage-slack-integrations">
  ## Slack 통합 보기 및 관리
</div>

팀 관리자는 팀의 Slack 인스턴스와 채널을 보고 관리할 수 있습니다.

1. W&amp;B에 로그인한 다음 **Team Settings**로 이동합니다.
2. **Slack channel integrations** 섹션에서 각 Slack 대상을 확인합니다.
3. 휴지통 아이콘을 클릭하여 대상을 삭제합니다.

<div id="create-an-automation">
  ## 자동화 만들기
</div>

[Slack 통합을 추가](#add-a-slack-integreation)한 후 **Registry** 또는 **Project**를 선택하고, 다음 단계에 따라 Slack 채널에 알림을 보내는 자동화를 만드세요.

<Tabs>
  <Tab title="Registry">
    레지스트리 관리자는 해당 레지스트리에서 자동화를 만들 수 있습니다.

    1. W&amp;B에 로그인합니다.
    2. 레지스트리 이름을 클릭하여 세부 정보를 확인합니다.
    3. 레지스트리 범위의 자동화를 만들려면 **Automations** 탭을 클릭한 후 **Create automation**을 클릭합니다. 레지스트리 범위로 설정된 자동화는 해당 레지스트리의 모든 컬렉션(향후 생성되는 컬렉션 포함)에 자동으로 적용됩니다.
    4. 감시할 [이벤트](/ko/models/automations/automation-events/#registry-events)를 선택합니다.

       이벤트에 따라 추가 필드가 표시되면 해당 내용을 입력합니다. 예를 들어 **An artifact alias is added**를 선택하면 **Alias regex**를 지정해야 합니다.

       **Next step**을 클릭합니다.
    5. [Slack 통합](#add-a-slack-integration)을 소유한 팀을 선택합니다.
    6. **Action type**을 **Slack notification**으로 설정합니다. Slack 채널을 선택한 후 **Next step**을 클릭합니다.
    7. 자동화 이름을 입력합니다. 필요에 따라 설명도 입력할 수 있습니다.
    8. **Create automation**을 클릭합니다.
  </Tab>

  <Tab title="Project">
    W&amp;B 관리자는 프로젝트에서 자동화를 만들 수 있습니다.

    1. W&amp;B에 로그인합니다.
    2. 프로젝트 페이지로 이동하여 **Automations** 탭을 클릭한 후 **Create automation**을 클릭합니다.

       또는 워크스페이스의 선 그래프에서 해당 그래프에 표시된 지표에 대한 [실행 지표 자동화](/ko/models/automations/automation-events/#run-events)를 빠르게 만들 수 있습니다. 패널 위에 마우스를 올린 후 패널 상단의 벨 아이콘을 클릭합니다.

       <Frame>
         <img src="/images/automations/run_metric_automation_from_panel.png" alt="자동화 벨 아이콘 위치" />
       </Frame>
    3. 감시할 [이벤트](/ko/models/automations/automation-events/#project)를 선택합니다.

       1. 표시되는 추가 필드를 입력합니다. 예를 들어 **An artifact alias is added**를 선택하면 **Alias regex**를 지정해야 합니다.

          1. 실행에 의해 트리거되는 자동화의 경우, 필요에 따라 하나 이상의 실행 필터를 지정합니다.

             * **Filter to one user&#39;s runs**: 지정한 사용자가 만든 실행만 포함합니다. 토글을 클릭하여 필터를 활성화한 후 사용자 이름을 지정합니다.
             * **Filter on run name**: 지정한 정규 표현식과 이름이 일치하는 실행만 포함합니다. 토글을 클릭하여 필터를 활성화한 후 정규 표현식을 지정합니다.
       2. **Next step**을 클릭합니다.
    4. [Slack 통합](#add-a-slack-integration)을 소유한 팀을 선택합니다.
    5. **Action type**을 **Slack notification**으로 설정합니다. Slack 채널을 선택한 후 **Next step**을 클릭합니다.
    6. 자동화 이름을 입력합니다. 필요에 따라 설명도 입력할 수 있습니다.
    7. **Create automation**을 클릭합니다.
  </Tab>
</Tabs>

<div id="view-and-manage-automations">
  ## 자동화 보기 및 관리
</div>

<Tabs>
  <Tab title="Registry">
    Registry의 **Automations** 탭에서 Registry 자동화를 관리할 수 있습니다.

    * 자동화의 세부 정보를 보려면 해당 이름을 클릭합니다.
    * 자동화를 수정하려면 해당 자동화의 작업 `...` 메뉴를 클릭한 다음 **Edit automation**을 클릭합니다.
    * 자동화를 삭제하려면 해당 자동화의 작업 `...` 메뉴를 클릭한 다음 **Delete automation**을 클릭합니다. 삭제를 완료하려면 확인이 필요합니다.
  </Tab>

  <Tab title="Project">
    W&amp;B 관리자는 프로젝트의 **Automations** 탭에서 해당 프로젝트의 자동화를 보고 관리할 수 있습니다.

    * 자동화의 세부 정보를 보려면 해당 이름을 클릭합니다.
    * 자동화를 수정하려면 해당 자동화의 작업 `...` 메뉴를 클릭한 다음 **Edit automation**을 클릭합니다.
    * 자동화를 삭제하려면 해당 자동화의 작업 `...` 메뉴를 클릭한 다음 **Delete automation**을 클릭합니다. 삭제를 완료하려면 확인이 필요합니다.
  </Tab>
</Tabs>
