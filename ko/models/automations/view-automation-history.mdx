---
title: 자동화 기록 보기
---

<Note>
  이 기능을 사용하려면 Enterprise 라이선스가 필요합니다. 다음 환경에서만 사용할 수 있습니다:

  * W&amp;B Multi-tenant Cloud
  * W&amp;B Dedicated Cloud
  * W&amp;B Self-Managed v0.75.0+
</Note>

이 페이지에서는 W&amp;B [automations](/ko/models/automations)의 실행 기록을 조회하고 이해하는 방법을 설명합니다. 여기에는 자동화를 트리거한 원인, 수행된 작업, 성공 또는 실패 여부 등이 포함됩니다.

각 실행된 자동화는 다음 정보를 포함하는 레코드를 생성합니다:

* **Execution timestamp**: 자동화가 트리거된 시각.
* **Triggering event**: 자동화를 트리거한 구체적인 이벤트.
* **Status**: 실행 상태. [Execution status](#execution-status)를 참조하세요.
* **Action details**: Slack 채널 알림 전송이나 webhook 실행과 같이 수행된 작업에 대한 정보.
* **Result details**: 실패한 실행의 오류를 포함하여, 자동화 실행의 최종 결과에 대한 추가 정보(있는 경우).

사용 사례에 따라 자동화 기록을 조회하는 방법에 대한 자세한 안내를 보려면 **Registry** 또는 **Project** 탭을 선택하세요.

<Tabs>
  <Tab title="Registry">
    1. 왼쪽 사이드바에서 **Registry**를 클릭해 registry로 이동합니다.
    2. 목록에서 registry를 선택합니다.
    3. **Automations** 탭에서 registry의 자동화를 확인합니다. **Last execution** 타임스탬프를 클릭하여 실행 기록 세부 정보를 확인합니다. 검색 창을 사용해 자동화 이름으로 필터링할 수 있고, 마지막 트리거 날짜로 정렬해 최근에 실행된 자동화를 찾을 수 있습니다.
    4. **Automations history** 탭에서 이벤트, 작업, 상태를 포함한 registry의 자동화 실행을 가장 최근 실행부터 과거 순으로 확인합니다. 특정 실행의 세부 정보를 보려면 실행 타임스탬프를 클릭합니다.

    <Tip>컬렉션에 연관된 자동화 실행이 있는 경우, ![Collection automation execution symbol, a circle with a right-pointing arrow](/images/automations/collection-automation-execution-icon.png) 아이콘과 함께 연관된 실행 횟수가 표시됩니다.</Tip>
  </Tab>

  <Tab title="Project">
    1. 왼쪽 내비게이션에서 **Automations** 탭을 클릭합니다. 프로젝트의 자동화가 표시됩니다. **Last execution** 타임스탬프를 클릭하여 실행 기록 세부 정보를 확인합니다. 검색 창을 사용해 자동화 이름으로 필터링할 수 있고, 마지막 트리거 날짜로 정렬해 최근에 실행된 자동화를 찾을 수 있습니다.
    2. **History** 탭에서 가장 최근 실행부터 시작해 프로젝트 자동화의 모든 실행을 시간 역순으로 확인합니다. 각 실행의 메타데이터(이벤트, 작업, 상태)가 표시됩니다. 특정 실행의 세부 정보를 보려면 실행 타임스탬프를 클릭합니다.
  </Tab>
</Tabs>

<div id="understanding-execution-details">
  ## 실행 상세 정보 이해하기
</div>

각 자동화 실행은 다음 상태 중 하나를 가집니다:

* **Finished**: 자동화가 모든 작업을 성공적으로 완료했습니다.
* **Failed**: 자동화 실행 중 오류가 발생하여 정상적으로 종료되지 않았습니다.
* **Pending**: 자동화가 실행 대기 상태입니다.

실행 기록에서 아무 실행이나 클릭하여 세부 정보를 확인합니다:

* **이벤트 상세 정보**: 자동화를 트리거한 특정 이벤트로, 다음을 포함합니다:
  * 이벤트 유형 (예: &quot;New artifact version&quot;, &quot;Run completed&quot;)
  * 엔터티 정보 (실행 ID, 아티팩트 이름 등)
  * 이벤트를 트리거한 사용자 (해당되는 경우)

* **액션 상세 정보**: 자동화가 수행하려고 시도한 작업에 대한 정보:
  * 액션 유형 (Slack 알림 또는 webhook)
  * 대상 (Slack 채널 또는 webhook URL)
  * 전송된 페이로드 (webhook의 경우)

* **결과 정보**:
  * 응답 상태 (webhook의 경우)
  * 오류 메시지 또는 스택 트레이스 (실패한 실행의 경우)
