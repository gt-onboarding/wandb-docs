<div id="login">
  # login
</div>

▸ **login**(`apiKey`, `host?`): `Promise`\<`void`\>

제공된 API key를 사용하여 Weights & Biases (W&B)에 로그인합니다.
이 함수는 향후 사용을 위해 자격 증명을 netrc 파일에 저장하려고 시도하며,
파일 시스템에 쓸 수 없더라도 실행을 계속합니다.

<div id="parameters">
  #### 매개변수
</div>

| 이름 | 타입 | 설명 |
| :------ | :------ | :------ |
| `apiKey` | `string` | W&B API key입니다. |
| `host?` | `string` | (선택 사항) 호스트 이름입니다(보통은 커스텀 W&B 서버를 사용하는 경우에만 필요합니다). |

<div id="returns">
  #### 반환값
</div>

`Promise`\<`void`\>

`Throws`

API key가 지정되지 않았거나 Weave trace 서버에 대한 연결을 검증할 수 없는 경우 예외를 발생시킵니다.
