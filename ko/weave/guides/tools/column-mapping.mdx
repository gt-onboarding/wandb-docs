---
title: "데이터셋의 열 매핑하기"
description: "데이터셋의 열을 다른 이름에 매핑합니다. 이를 통해 데이터셋의 열 이름을 스코어러가 기대하는 열 이름과 일치시킬 수 있습니다."
---

<Tabs>
  <Tab title="Python">
    Weave Python SDK에서는 스코어러의 `column_map` 속성을 사용해 스코어러가 기대하는 매개변수 이름을 데이터셋의 열 이름에 매핑합니다. 매핑 형식은 `{scorer_parameter: dataset_column}`입니다.

    다음 예시는 `output` 및 `target` 매개변수를 데이터셋의 `model_output` 및 `answer` 열에 매핑합니다:

    ```python
    from weave.scorers import EmbeddingSimilarityScorer

    similarity_scorer = EmbeddingSimilarityScorer()

    similarity_scorer.column_map = {
        "output": "model_output",  # 모델이 생성한 텍스트
        "target": "answer"         # 기대 또는 기준 응답
    }
    ```

    스코어러 열 매핑에 대한 자세한 내용은 [Mapping Column Names with `column_map`](../evaluation/scorers#mapping-column-names-with-column_map)을 참고하십시오.
  </Tab>
  <Tab title="TypeScript">
    Weave TypeScript SDK에서는 열 매핑을 개별 스코어러가 아닌 `Evaluation` 객체의 `columnMapping` 옵션에서 설정합니다. 매핑 형식은 `{scorer_key: dataset_column}`입니다.

    다음 예시는 스코어러에서 사용하는 `expectedOutputTimesTwo`를 데이터셋의 `expected` 열에 매핑합니다:

    ```typescript
    import * as weave from 'weave';

    const myScorer = weave.op(
      ({modelOutput, datasetRow}) => {
        return modelOutput * 2 === datasetRow.expectedOutputTimesTwo;
      },
      {name: 'myScorer'}
    );

    const myEval = new weave.Evaluation({
      id: 'my-evaluation',
      dataset: [{expected: 2}],
      scorers: [myScorer],
      columnMapping: {expectedOutputTimesTwo: 'expected'},
    });
    ```

    TypeScript 스코어러 매개변수에 대한 자세한 내용은 [Scorer Keyword Arguments](../evaluation/scorers#scorer-keyword-arguments)를 참고하십시오.
  </Tab>
</Tabs>
