---
title: "Serve"
description: "Weave op과 모델을 API 엔드포인트로 제공하기"
---

어떤 Weave Model에 대한 Weave ref가 있다면 다음을 실행할 수 있습니다:

```
weave serve <ref>
```

해당 모델용 FastAPI 서버를 실행합니다. 모델을 상호작용 방식으로 쿼리하려면 [http://0.0.0.0:9996/docs](http://0.0.0.0:9996/docs)로 이동하세요.


<div id="install-fastapi">
  ## FastAPI 설치하기
</div>

```bash
pip install fastapi uvicorn
```


<div id="serve-model">
  ## 모델 서빙
</div>

터미널에서 다음 명령을 실행합니다:

```bash
weave serve <your model ref>
```

UI에서 해당 모델 페이지로 이동한 다음 모델 ref를 복사합니다. 형식은 다음과 같습니다:
`weave://your_entity/project-name/YourModel:<hash>`

이 모델을 사용하려면 Swagger UI 링크로 이동한 후 predict 엔드포인트를 클릭하고 &quot;Try it out!&quot;을 클릭합니다.
