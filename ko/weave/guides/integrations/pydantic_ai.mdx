[OpenTelemetry (OTEL)](https://opentelemetry.io/)을 사용해 Weave에서 [PydanticAI](https://ai.pydantic.dev/) 에이전트 및 도구 호출을 추적할 수 있습니다. PydanticAI는 Pydantic 팀이 만든 Python 에이전트 프레임워크로, 생성형 AI를 활용한 프로덕션급 애플리케이션을 쉽고 타입 안전하게(type-safe) 구축할 수 있게 해줍니다. 모든 에이전트 및 도구 호출을 추적하기 위해 OTEL을 사용합니다.

<Tip>
  Weave에서 OTEL 추적에 대한 자세한 내용은 [Send OTEL Traces to Weave](../tracking/otel)를 참조하세요.
</Tip>

이 가이드는 OTEL을 사용해 PydanticAI 에이전트 및 도구 호출을 추적하고, 이러한 트레이스를 Weave에서 시각화하는 방법을 설명합니다. 필요한 종속성을 설치하고, OTEL 트레이서를 구성하여 Weave로 데이터를 전송하고, PydanticAI 에이전트와 도구에 계측을 추가하는 방법을 다룹니다. 또한 애플리케이션의 모든 에이전트에서 기본적으로 추적을 활성화하는 방법도 살펴봅니다.

<div id="prerequisites">
  ## 사전 준비 사항
</div>

시작하기 전에 필요한 OTEL 종속성을 설치하세요.

```bash
pip install opentelemetry-sdk OTELemetry-exporter-otlp-proto-http
```

그런 다음 [Weave에서 OTEL 트레이싱을 구성](#configure-otel-tracing-in-weave)합니다.

<div id="configure-otel-tracing-in-weave">
  ### Weave에서 OTEL 트레이싱 구성하기
</div>

PydanticAI에서 Weave로 트레이스를 전송하려면, `TracerProvider`와 `OTLPSpanExporter`를 사용해 OTEL을 구성합니다. exporter를 [인증 및 프로젝트 식별을 위한 올바른 엔드포인트와 HTTP 헤더](#required-configuration)로 설정하세요.

<Warning>
  API key 및 프로젝트 정보와 같은 민감한 환경 변수는 `.env`와 같은 환경 파일에 저장하고, `os.environ`을 사용해 로드할 것을 권장합니다. 이렇게 하면 자격 증명을 안전하게 보호하고 코드베이스 밖에 둘 수 있습니다.
</Warning>

<div id="required-configuration">
  ### 필수 설정
</div>

* **엔드포인트:** `https://trace.wandb.ai/otel/v1/traces`
* **헤더:**
  * `Authorization`: W&amp;B API key를 사용하는 Basic 인증
  * `project_id`: W&amp;B 엔터티/프로젝트 이름(예: `myteam/myproject`)

<div id="example-set-up">
  ### 예시 설정
</div>

다음 코드 스니펫은 PydanticAI 애플리케이션에서 생성된 OTEL trace를 Weave로 전송하도록 OTLP span exporter 및 tracer provider를 구성하는 방법을 보여줍니다.

```python lines
import base64
import os
from opentelemetry.exporter.otlp.proto.http.trace_exporter import OTLPSpanExporter
from opentelemetry.sdk import trace as trace_sdk
from opentelemetry.sdk.trace.export import SimpleSpanProcessor

# 환경 변수에서 민감한 값 로드
WANDB_BASE_URL = "https://trace.wandb.ai"
PROJECT_ID = os.environ.get("WANDB_PROJECT_ID")  # W&B 엔터티/프로젝트 이름 예: "myteam/myproject"
WANDB_API_KEY = os.environ.get("WANDB_API_KEY")  # W&B API key

OTEL_EXPORTER_OTLP_ENDPOINT = f"{WANDB_BASE_URL}/otel/v1/traces"
AUTH = base64.b64encode(f"api:{WANDB_API_KEY}".encode()).decode()

OTEL_EXPORTER_OTLP_HEADERS = {
    "Authorization": f"Basic {AUTH}",
    "project_id": PROJECT_ID,
}

# 엔드포인트 및 헤더로 OTLP 스팬 익스포터 생성
exporter = OTLPSpanExporter(
    endpoint=OTEL_EXPORTER_OTLP_ENDPOINT,
    headers=OTEL_EXPORTER_OTLP_HEADERS,
)

# 트레이서 프로바이더 생성 및 익스포터 추가
tracer_provider = trace_sdk.TracerProvider()
tracer_provider.add_span_processor(SimpleSpanProcessor(exporter))
```

<div id="trace-pydanticai-agents-with-otel">
  ## OTEL로 PydanticAI 에이전트 추적하기
</div>

PydanticAI 에이전트를 추적하고 추적 데이터를 Weave로 전송하려면, 트레이서 프로바이더로 구성한 `InstrumentationSettings` 객체를 에이전트 생성자에 전달하세요. 이렇게 하면 OTEL 설정에 따라 모든 에이전트와 도구 호출이 추적됩니다.

다음 예시는 추적이 활성화된 간단한 에이전트를 생성하는 방법을 보여줍니다. 핵심 단계는 에이전트를 초기화할 때 `instrument` 인수를 설정하는 것입니다:

```python lines
from pydantic_ai import Agent
from pydantic_ai.models.instrumented import InstrumentationSettings

# OTEL 추적을 사용하는 PydanticAI 에이전트 생성
agent = Agent(
    "openai:gpt-4o",
    instrument=InstrumentationSettings(tracer_provider=tracer_provider),
)

result = agent.run_sync("What is the capital of France?")
print(result.output)
```

모든 에이전트 호출은 추적되어 Weave로 전송됩니다.

<div id="trace-pydanticai-tools-with-otel">
  ## OTEL을 사용하여 PydanticAI Tool 추적하기
</div>

Weave는 OTEL로 계측된 모든 PydanticAI operation을 추적할 수 있으며, 여기에는 에이전트와 툴 호출이 모두 포함됩니다. 즉, 에이전트가 툴(예: `@agent.tool_plain` 데코레이터가 적용된 함수)을 호출할 때, 툴의 입력, 출력, 그리고 모델의 추론 과정까지 전체 상호작용이 Weave에서 캡처되고 시각화됩니다.

다음 예제는 시스템 프롬프트와 툴을 함께 사용하는 에이전트를 생성하는 방법을 보여줍니다. 에이전트와 툴 모두에 대해 추적이 자동으로 활성화됩니다:

```python lines
from pydantic_ai import Agent
from pydantic_ai.models.instrumented import InstrumentationSettings

# 시스템 프롬프트와 OTEL 추적을 사용하여 PydanticAI 에이전트 생성
agent = Agent(
    "openai:gpt-4o",
    system_prompt=(
        "You are a helpful assistant that can multiply numbers. "
        "When asked to multiply numbers, use the multiply tool."
    ),
    instrument=InstrumentationSettings(tracer_provider=tracer_provider),
)

# 도구 정의
@agent.tool_plain
def multiply(a: int, b: int) -> int:
    """두 숫자를 곱합니다."""
    return a * b

# 에이전트에게 도구 사용 요청
result = agent.run_sync("What is 7 multiplied by 8?")
print(result.output)
```

  ![도구 호출 트레이스 시각화](/weave/guides/integrations/imgs/pydantic_ai/pydanticai_tool_call.png)
</Frame>

에이전트 호출과 도구 호출 모두 Weave에서 추적되므로, 애플리케이션의 전체 추론 및 실행 경로를 확인할 수 있습니다.

<div id="instrument-all-agents-by-default">
  ## 기본적으로 모든 에이전트 계측하기
</div>

애플리케이션의 모든 PydanticAI 에이전트에 OTEL 트레이싱을 적용하려면 `Agent.instrument_all()` 메서드를 사용하세요. 이 메서드는 `instrument` 매개변수를 명시적으로 지정하지 않은 모든 에이전트에 대해 기본 `InstrumentationSettings` 인스턴스를 설정합니다.

```python lines
from pydantic_ai import Agent
from pydantic_ai.models.instrumented import InstrumentationSettings

# 모든 에이전트에 대한 기본 계측 설정
Agent.instrument_all(InstrumentationSettings(tracer_provider=tracer_provider))

# 이제 새로운 에이전트는 기본적으로 이 계측을 사용합니다
agent1 = Agent("openai:gpt-4o")
agent2 = Agent("openai:gpt-4o", system_prompt="Be helpful.")

result = agent1.run_sync("What is the capital of France?")
print(result.output)
```

이 방법은 더 큰 규모의 애플리케이션에서 설정을 반복하지 않고 모든 에이전트 전반에 일관된 트레이싱을 적용하고 싶을 때 유용합니다. 자세한 내용은 [PydanticAI OTEL 문서](https://ai.pydantic.dev/logfire/#using-logfire)를 참조하세요.
