* LLM 애플리케이션을 [관측하고 디버깅](/ko/weave/quickstart)하기
* LLM 판정자와 사용자 정의 스코어러를 사용해 애플리케이션의 응답을 [평가](/ko/weave/tutorial-eval)하기

<div id="install-weave">
  ## Weave 설치
</div>

W&amp;B Weave는 Python 및 TypeScript용 라이브러리를 제공합니다. Weave 라이브러리를 설치하려면 다음 명령을 실행하세요:

<Tabs>
  <Tab title="Python">
    ```bash
    pip install weave
    ```
  </Tab>

  <Tab title="TypeScript">
    ```bash
    pnpm install weave
    ```
  </Tab>
</Tabs>

Weave 라이브러리 사용을 시작하려면 먼저 [Weights &amp; Biases (W&amp;B) 계정](https://wandb.ai)과 [User Settings에서 API key](https://wandb.ai/settings)를 생성하세요. API key를 사용해 W&amp;B 계정에 인증하고 데이터 전송을 시작할 수 있습니다.
