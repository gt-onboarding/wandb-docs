API key를 생성하려면 **Personal API key** 또는 **Service Account API key** 탭을 선택해 세부 정보를 확인하세요.

<Tabs>
  <Tab title="Personal API key">
    사용자 ID가 소유한 개인 API key를 생성하려면:

    1. W&amp;B에 로그인한 후, 사용자 프로필 아이콘을 클릭하고 **User Settings**를 클릭합니다.
    2. **Create new API key**를 클릭합니다.
    3. API key에 대한 설명용 이름을 입력합니다.
    4. **Create**를 클릭합니다.
    5. 표시된 API key를 즉시 복사하여 안전한 위치에 보관합니다.
  </Tab>
