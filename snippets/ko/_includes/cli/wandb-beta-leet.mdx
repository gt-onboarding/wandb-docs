LEET는 로컬 터미널 UI로서 W&amp;B 실행의 통계, 메트릭, 시스템 상태를 확인할 수 있습니다. LEET는 SSH 또는 `tmux` 같은 도구를 사용해 원격 시스템이나 HPC 환경에서 작업하는 사용자를 위해 설계된 키보드 중심 인터페이스입니다.

![Screenshot demonstrating viewing a run in the LEET terminal UI](/images/leet/leet-tui.png)

주요 기능은 다음과 같습니다:

* **키보드 중심 내비게이션**: 모든 기능을 키보드 단축키로 사용할 수 있음
* **실시간 업데이트**: 실행이 진행되는 동안 `.wandb` 파일을 실시간으로 모니터링
* **메트릭 필터링**: glob 패턴이나 부분 문자열 일치로 메트릭 필터링
* **스마트 줌**: 마우스 휠로 줌해도 최신 데이터 포인트가 항상 화면에 보이도록 유지
* **구성 가능한 그리드**: 메트릭 및 시스템 표시를 위한 행과 열의 개수 구성 가능
* **사람이 읽기 쉬운 형식**: 시스템 메트릭을 친숙한 단위로 표시 (예: &quot;GPU Utilization (%)&quot;, &quot;RAM Used (GB)&quot;)

LEET는 세 패널 레이아웃을 제공합니다:

* **왼쪽 사이드바**: 환경 변수, 구성, 요약 통계를 보여주는 실행 개요
* **가운데 패널**: 기록된 메트릭에 대해 점자 스타일의 선형 차트를 보여주는 메트릭 그리드
* **오른쪽 사이드바**: GPU 사용률, RAM, CPU 및 기타 시스템 상태 지표를 표시하는 시스템 메트릭
